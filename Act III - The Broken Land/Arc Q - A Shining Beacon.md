_Une aventure pour cinq personnages de niveau 7._

Dans cet arc, à leur retour du château Ravenloft dans [Arc P : Le cambriolage de Ravenloft](Arc%20P%20-%20Ravenloft%20Heist.md), les joueurs apprennent que <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> de l'abbaye de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a> compte s'emparer du cœur de la <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-baroness-anna-krezkova">baronne Anna Krezkova</a> avant la tombée de la nuit. Pendant ce temps, <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril Stoyanovich</a>, un <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup-garou">loup-garou</a> <a href="../Appendices/Bestiary.md#en-werewolf"><sup>fiche</sup></a> mutant, les traque, tandis que le <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">commandant Vladimir Horngaard</a> rassemble ses <a href="https://www.aidedd.org/dnd/monstres.php?vf=chevalier">chevaliers</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-knight-monstre"><sup>fiche</sup></a> <a href="https://www.aidedd.org/dnd/monstres.php?vf=revenant">revenants</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-revenant-monstre"><sup>fiche</sup></a> pour exécuter leur condamnation à mort. Les joueurs pourront-ils ramener <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> sur le droit chemin, renverser <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> et allumer le phare d'Argynvostholt, ou leurs efforts pour rendre la lumière à la vallée barovienne connaîtront-ils une fin atroce et sanglante ?
<a id="en-q1-flight-from-ravenloft" data-traduction="ancre"></a>
# Q1. Fuite de Ravenloft
Selon leur moyen d'évasion, les joueurs qui fuient le château Ravenloft après [Arc P : Le cambriolage de Ravenloft](Arc%20P%20-%20Ravenloft%20Heist.md) peuvent chercher un refuge pour la nuit en différents lieux.
<a id="en-q1a-the-teleportation-brazier" data-traduction="ancre"></a>
## Q1a. Le brasero de téléportation
Les joueurs qui s'échappent du château Ravenloft grâce au brasero de téléportation de la <span class="citation">K78. Salle du brasero (p. 82)</span> peuvent se téléporter aux endroits décrits dans [Arc P : Le cambriolage de Ravenloft](Arc%20P%20-%20Ravenloft%20Heist.md#en-p11e-brazier-room). Ils peuvent ensuite trouver refuge comme suit :

***Village de Barovie.*** Si les joueurs se téléportent au cimetière du village de Barovie, <a href="../Appendices/Non-Player%20Characters.md#en-ismark-kolyanovich">Ismark Kolyanovich</a> les laisse volontiers se reposer dans les chambres d'amis de la demeure du bourgmestre. Bien que surpris d'apprendre qu'<a href="../Appendices/Non-Player%20Characters.md#en-ireena-kolyana">Ireena</a> s'est jointe à leur quête pour vaincre <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-strahd-von-zarovich">Strahd</a>, il est réconforté de constater que le temps passé à leurs côtés l’a rendue plus forte, plus sûre d’elle et plus déterminée.

***Ville de Vallaki.*** Si les joueurs se téléportent dans l'échoppe du fabricant de cercueils à Vallaki, ils peuvent trouver refuge à l'auberge de l'Eau bleue, à l'église Saint-Andral ou à Wachterhaus, s'ils entretiennent de bonnes relations avec <a href="../Appendices/Non-Player%20Characters.md#en-lady-fiona-wachter">dame Fiona Wachter</a> et taisent leur assaut contre le château Ravenloft.

***Village de Krezk.*** Si les joueurs se téléportent au sanctuaire du Soleil blanc, dans le village de Krezk, ils peuvent trouver refuge dans la chaumière des Krezkov, décrite dans [Arc K : L'abbaye déchue](Arc%20K%20-%20The%20Fallen%20Abbey.md#en-k1a-the-krezkovs-cottage). <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-the-krezkovs">Les Krezkov</a> reprennent espoir s'ils apprennent que les joueurs ont obtenu l'*<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-campagne-icon-of-dawns-grace">Icône de la Grâce de l'Aube</a>* dans la crypte de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a> au château Ravenloft et comptent l'utiliser pour guérir la folie de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>. Si <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil Toranescu</a> accompagne les joueurs, le <a href="../Appendices/Non-Player%20Characters.md#en-baron-dmitri-krezkov">baron Dmitri Krezkov</a> reconnaît avec colère « le <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup">loup</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-wolf-monstre"><sup>fiche</sup></a> qui lui a volé sa sœur », <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zuleika-toranescu">Zuleika</a>, et insiste pour qu'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a> dorme dehors, à moins qu'on ne le persuade du contraire.

> [!lore]+ **<a href="../Appendices/Non-Player%20Characters.md#en-baron-dmitri-krezkov">Dmitri</a> & <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a>**
> <a href="../Appendices/Non-Player%20Characters.md#en-baron-dmitri-krezkov">Dmitri</a> ne croit pas sérieusement qu'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a> ait enlevé <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zuleika-toranescu">Zuleika</a> ou l'ait contrainte à rejoindre la meute de <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup-garou">loups-garous</a> <a href="../Appendices/Bestiary.md#en-werewolf"><sup>fiche</sup></a>. Il lui en veut cependant d'avoir « attiré » <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zuleika-toranescu">Zuleika</a> loin de Krezk avec des histoires invraisemblables sur le « don » de la lycanthropie, que <a href="../Appendices/Non-Player%20Characters.md#en-baron-dmitri-krezkov">Dmitri</a> considère comme une malédiction. Si on le contredit, <a href="../Appendices/Non-Player%20Characters.md#en-baron-dmitri-krezkov">Dmitri</a> serre les dents et crache : « Il a convaincu ma sœur que c'était un *don* d'être un monstre, une *bête*. Il lui a rempli la tête de mensonges et de récits insensés, puis me l'a enlevée… nous l'a enlevée à tous. »

***Tour de Van Richten.*** Si les joueurs se téléportent à la tour de <a href="../Appendices/Non-Player%20Characters.md#en-dr-rudolph-van-richten">Van Richten</a>, ils peuvent s'y abriter ou se rendre au village de Krezk. Le trajet entre la tour et Krezk couvre trois milles et demi et prend une heure et dix minutes.

***Ruines de Berez.*** Si les joueurs se téléportent au monument de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-marina-ulrich">Marina</a>, à Berez, ils peuvent s'abriter dans le <span class="citation">U2. Manoir Ulrich (p. 162)</span> ou le <span class="citation">U4. Cimetière de l'église (p. 164)</span>, leur arrivée dissimulée par l'épais brouillard qui s'accroche au marais.

Les joueurs peuvent aussi se rendre de Berez à la ville de Vallaki, à la tour de <a href="../Appendices/Non-Player%20Characters.md#en-dr-rudolph-van-richten">Van Richten</a> ou au village de Krezk :

* Le trajet de Berez à Vallaki couvre quatre milles et demi et prend une heure et trente minutes.
* Le trajet de Berez au lac Baratok couvre sept milles et prend deux heures et vingt minutes.
* Le trajet de Berez à Krezk couvre huit milles et trois quarts et prend trois heures.

***Vieille route de Svalich.*** Si les joueurs se téléportent au monument de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-marina-ulrich">Marina</a>, à Berez, ils peuvent camper sur la vieille route de Svalich ou à proximité. Une heure après avoir installé leur camp, ils font alors la rencontre aléatoire des <span class="citation"><a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-campagne-strahd-zombie">Zombies de Strahd</a> (p. 31)</span>, avec huit **<a href="https://www.aidedd.org/dnd/monstres.php?vf=zombi">zombis</a> <a href="../Appendices/Bestiary.md#en-zombie"><sup>fiche</sup></a>** à la place des **<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-campagne-strahd-zombie">zombies de Strahd</a>**.

***Magicien des Vins.*** Si les joueurs se téléportent au Magicien des Vins, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-the-martikovs">les Martikov</a> leur offrent volontiers un endroit où passer la nuit. Lorsqu'ils repartent le lendemain matin, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-davian-martikov">Davian</a> envoie deux **<a href="https://www.aidedd.org/dnd/monstres.php?vf=nuee-de-corbeaux">nuées de corbeaux</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-swarm-of-ravens-monstre"><sup>fiche</sup></a>** les accompagner jusqu'à leur destination. (Les <a href="https://www.aidedd.org/dnd/monstres.php?vf=corbeau">corbeaux</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-raven-monstre"><sup>fiche</sup></a> repartent dès que les joueurs atteignent Vallaki, Krezk ou Argynvostholt, selon leur première étape.)

***Col de Tsolenka.*** Si les joueurs se téléportent au col de Tsolenka, ils peuvent dormir dans la tour de garde. Les **<a href="https://www.aidedd.org/dnd/monstres.php?vf=vrock">vrocks</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-vrock-monstre"><sup>fiche</sup></a>** pétrifiés n'attaquent pas les joueurs qui contournent le corps de garde depuis le côté est de la herse.

Les joueurs peuvent aussi se rendre de la tour de garde à la ville de Vallaki, à la tour de <a href="../Appendices/Non-Player%20Characters.md#en-dr-rudolph-van-richten">Van Richten</a> ou au village de Krezk :

* Le trajet de la tour à Krezk couvre onze milles et prend trois heures et quarante minutes.
* Le trajet de la tour au lac Baratok couvre dix milles et demi et prend trois heures et trente minutes.
* Le trajet de la tour à Vallaki couvre treize milles et un quart et prend quatre heures et trente minutes.

## Q1b. Le piton
Les joueurs qui s'échappent du château Ravenloft en descendant la falaise sud-est du piton de Ravenloft arrivent juste au nord du village de Barovie, à faible distance de la limite nord du <span class="citation">E6. Cimetière (p. 48)</span>. Ils peuvent trouver refuge dans le village comme décrit dans [Q1a. Le brasero de téléportation](#en-q1a-the-teleportation-brazier).
<a id="en-q1c-the-drawbridge" data-traduction="ancre"></a>
## Q1c. Le pont-levis
Les joueurs qui s'échappent du château Ravenloft en traversant le gouffre à l'ouest peuvent trouver refuge comme suit :

***Vieille route de Svalich.*** Les joueurs peuvent camper sur la vieille route de Svalich ou à proximité, comme décrit dans [Q1a. Le brasero de téléportation](#en-q1a-the-teleportation-brazier).

***Ville de Vallaki.*** Le trajet du château Ravenloft à Vallaki couvre onze milles et un quart et prend trois heures et quarante-cinq minutes. Les joueurs peuvent y trouver refuge comme décrit dans [Q1a. Le brasero de téléportation](#en-q1a-the-teleportation-brazier).

***Village de Barovie.*** Le trajet du château Ravenloft à Barovie couvre treize milles et un quart et prend quatre heures et trente minutes. Les joueurs peuvent y trouver refuge comme décrit dans [Q1a. Le brasero de téléportation](#en-q1a-the-teleportation-brazier).

***Campement de l'étang de Tser.*** Le trajet du château Ravenloft à l'étang de Tser couvre douze milles et prend quatre heures. <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-arturi-radanavich">Arturi Radanavich</a> n'y est plus : il est parti trois jours auparavant, sans prévenir.

Si les joueurs lui rendent visite, <a href="../Appendices/Non-Player%20Characters.md#en-madam-eva">madame Eva</a> refuse de leur lire l'avenir une seconde fois et les avertit simplement qu'ils ont franchi « le dernier seuil du chemin qu'ils ont choisi ». S'ils lui apprennent qu'ils connaissent son véritable nom, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-katarina">Katarina</a>, <a href="../Appendices/Non-Player%20Characters.md#en-madam-eva">madame Eva</a> les félicite avec une pointe d'ironie pour leur perspicacité. Elle peut alors leur communiquer les informations concernant sa relation avec <a href="../Appendices/Non-Player%20Characters.md#en-varushka">Varushka</a> dans [Arc O : Dîner avec le Djavo](Arc%20O%20-%20Dinner%20with%20the%20Devil.md).

Si les joueurs suggèrent qu'elle est liée aux Dames des <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-fanes">Sanctuaires</a>, le regard de <a href="../Appendices/Non-Player%20Characters.md#en-madam-eva">madame Eva</a> se durcit et elle les avertit froidement : « N'invoquez pas les noms des Anciens, de peur d'attirer une attention indésirable. » (Elle ne s'explique pas davantage.)

# Q2. La supplique de Dmitri
<a id="en-q2a-a-dark-omen" data-traduction="ancre"></a>
## Q2a. Un sombre présage
À l'aube du premier jour suivant le raid des joueurs contre le château Ravenloft, une plume blanche comme neige descend de l'abbaye de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a> et se pose sur le rebord de la fenêtre de la cuisine des Krezkov. <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-baroness-anna-krezkova">Anna</a> et <a href="../Appendices/Non-Player%20Characters.md#en-baron-dmitri-krezkov">Dmitri</a> reconnaissent le message que leur avait promis <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> : il compte venir prendre le cœur d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-baroness-anna-krezkova">Anna</a> au crépuscule.

Si les joueurs ne sont pas déjà à Krezk, <a href="../Appendices/Non-Player%20Characters.md#en-baron-dmitri-krezkov">Dmitri</a> part pour Vallaki avec deux **<a href="https://www.aidedd.org/dnd/monstres.php?vf=garde">gardes</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-guard-monstre"><sup>fiche</sup></a>** de Krezk, dans l'espoir de les y trouver.

* Si les joueurs se rendent à Krezk depuis Berez, le col de Tsolenka, la tour de <a href="../Appendices/Non-Player%20Characters.md#en-dr-rudolph-van-richten">Van Richten</a> ou une portion de la vieille route de Svalich à l'ouest de Vallaki, ils rencontrent <a href="../Appendices/Non-Player%20Characters.md#en-baron-dmitri-krezkov">Dmitri</a> et ses compagnons à la <span class="citation">R. Croisée de la rivière du Corbeau (p. 40)</span>.
* Sinon, <a href="../Appendices/Non-Player%20Characters.md#en-baron-dmitri-krezkov">Dmitri</a> et ses compagnons arrivent à Vallaki deux heures après l'aube. Ils laissent un message aux <a href="https://www.aidedd.org/dnd/monstres.php?vf=garde">gardes</a> de la porte ouest, puis se rendent à l'auberge de l'Eau bleue en espérant y trouver les joueurs.

Si les joueurs ont passé la nuit dans la chaumière des Krezkov, de discrets sanglots venus de la cuisine les réveillent. <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-baroness-anna-krezkova">Anna</a> tente d'y rassurer <a href="../Appendices/Non-Player%20Characters.md#en-baron-dmitri-krezkov">Dmitri</a> en lui disant que « tout ira bien », tandis que celui-ci, en larmes, jure désespérément qu'il « ne laissera rien lui arriver ».

Quel que soit l'endroit où il rencontre les joueurs, <a href="../Appendices/Non-Player%20Characters.md#en-baron-dmitri-krezkov">Dmitri</a>, angoissé, leur annonce que <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> compte prendre le cœur d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-baroness-anna-krezkova">Anna</a> au crépuscule et qu'il dévastera probablement Krezk si elle ne se rend pas à l'abbaye de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a> d'ici là. Si les joueurs ne proposent pas leur aide, <a href="../Appendices/Non-Player%20Characters.md#en-baron-dmitri-krezkov">Dmitri</a> les supplie d'intervenir en faveur d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-baroness-anna-krezkova">Anna</a>, « si ce n'est pour nous, alors pour nos enfants ».
<a id="en-q2b-the-old-svalich-road" data-traduction="ancre"></a>
## Q2b. La vieille route de Svalich
<a id="en-journey-to-vallaki" data-traduction="ancre"></a>
### Trajet vers Vallaki
<a id="en-the-raven-guard" data-traduction="ancre"></a>
#### La garde de corbeaux
Si les joueurs ont dormi à l'est de Vallaki après leur évasion du château Ravenloft, par exemple au village de Barovie ou au campement de l'étang de Tser, ils découvrent au réveil quatre **<a href="https://www.aidedd.org/dnd/monstres.php?vf=nuee-de-corbeaux">nuées de corbeaux</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-swarm-of-ravens-monstre"><sup>fiche</sup></a>** qui montent la garde sur les toits ou les arbres voisins. Les <a href="https://www.aidedd.org/dnd/monstres.php?vf=corbeau">corbeaux</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-raven-monstre"><sup>fiche</sup></a> ont entendu les <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-keepers-of-the-feather">Gardiens de la Plume</a> parler de leurs exploits et leur font une garde d'honneur jusqu'à la ville de Vallaki.
<a id="en-the-wolves-ambush" data-traduction="ancre"></a>
#### L'embuscade des loups
Une heure avant d'atteindre Vallaki, les joueurs découvrent trois cadavres dispersés sur la route, comme décrit dans <span class="citation">Cadavre (p. 30)</span>. Deux sont ceux d'adultes baroviens tués par des <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup-sanguinaire">loups sanguinaires</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-dire-wolf-monstre"><sup>fiche</sup></a>, tandis que le troisième ressemble au joueur qui a le plus déplu à <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-strahd-von-zarovich">Strahd</a>.

Si le troisième cadavre disparaît en fondant, ou lorsque les joueurs s'apprêtent à quitter les lieux, six **<a href="https://www.aidedd.org/dnd/monstres.php?vf=loup-sanguinaire">loups sanguinaires</a>**, décrits dans <span class="citation"><a href="https://www.aidedd.org/dnd/monstres.php?vf=loup-sanguinaire">Loups sanguinaires</a> (p. 30)</span>, les attaquent, accompagnés de deux **<a href="https://www.aidedd.org/dnd/monstres.php?vf=epouvantail">épouvantails</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-scarecrow-monstre"><sup>fiche</sup></a>**, décrits dans <span class="citation"><a href="https://www.aidedd.org/dnd/monstres.php?vf=epouvantail">Épouvantails</a> (p. 31)</span>. <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup">Loups</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-wolf-monstre"><sup>fiche</sup></a> et <a href="https://www.aidedd.org/dnd/monstres.php?vf=epouvantail">épouvantails</a> combattent jusqu'à la mort, de même que les <a href="https://www.aidedd.org/dnd/monstres.php?vf=nuee-de-corbeaux">nuées de corbeaux</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-swarm-of-ravens-monstre"><sup>fiche</sup></a>, qui défendent farouchement les joueurs.

> [!combat]- **Équilibrer la vieille route de Svalich**
> Cette rencontre constitue un combat **éprouvant** pour cinq joueurs de niveau 7 accompagnés d'un allié de FP 2 (<a href="../Appendices/Non-Player%20Characters.md#en-ireena-kolyana">Ireena Kolyana</a>) et d'un allié de FP 4 (<a href="../Appendices/Non-Player%20Characters.md#en-ezmerelda-davenir">Ezmerelda d'Avenir</a>). Elle devrait leur coûter environ 37% de leur maximum total de points de vie. Pour un groupe plus petit ou plus grand, modifiez la rencontre comme suit :
> 
> * Trois joueurs. Réduisez le nombre de <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup-sanguinaire">loups sanguinaires</a> à 5 et celui des <a href="https://www.aidedd.org/dnd/monstres.php?vf=epouvantail">épouvantails</a> à un.
> * Quatre joueurs. Réduisez le nombre d'<a href="https://www.aidedd.org/dnd/monstres.php?vf=epouvantail">épouvantails</a> à un.
> * Six joueurs. Augmentez le nombre d'<a href="https://www.aidedd.org/dnd/monstres.php?vf=epouvantail">épouvantails</a> à trois.

#### Arrivée à Vallaki
À leur arrivée à Vallaki, les <a href="https://www.aidedd.org/dnd/monstres.php?vf=garde">gardes</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-guard-monstre"><sup>fiche</sup></a> de la porte apprennent aux joueurs que le <a href="../Appendices/Non-Player%20Characters.md#en-baron-dmitri-krezkov">baron Dmitri Krezkov</a> de Krezk les attend à l'auberge de l'Eau bleue. S'ils s'y rendent, ils le trouvent dans la salle commune, assis au comptoir, angoissé, devant un verre intact, tandis que <a href="../Appendices/Non-Player%20Characters.md#en-danika-dorakova">Danika</a> tente de le réconforter. La scène se déroule ensuite comme décrit dans [Q2a. Un sombre présage](#en-q2a-a-dark-omen).

## Trajet vers Krezk
En route pour Krezk, les joueurs rencontrent de nouveau le **<a href="https://www.aidedd.org/dnd/monstres.php?vf=revenant">revenant</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-revenant-monstre"><sup>fiche</sup></a>** qui garde le pont sur la rivière du Corbeau, décrit dans [Arc I : Les remparts de Krezk](../Act%20II%20-%20The%20Shadowed%20Town/Arc%20I%20-%20The%20Walls%20of%20Krezk.md#en-i1-the-road-to-krezk). Il les salue chaleureusement, mais une ombre passe sur son visage lorsqu'il les avertit que le vent porte de « sombres nouvelles » et qu'il pourrait être rappelé de son poste plus tôt que prévu.

Le <a href="https://www.aidedd.org/dnd/monstres.php?vf=revenant">revenant</a> ignore la nature de ces nouvelles, mais il sait que leur assaut contre le château Ravenloft a rendu le <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">commandant Vladimir Horngaard</a> furieux. Il ne sait pas comment <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> a appris leurs actes, mais suppose que les **<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-campagne-phantom-warrior">guerriers fantomatiques</a>** qui lui servent d'yeux et d'oreilles dans le <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-ethereal-plane">plan Éthéré</a> l'en ont informé.

Lorsque les joueurs repartent, le <a href="https://www.aidedd.org/dnd/monstres.php?vf=revenant">revenant</a> leur souhaite bonne chance et leur fait ses adieux avec solennité. Il ajoute, presque nostalgique : « Puisse le <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-morninglord">Seigneur de l'Aube</a> vous abriter dans la lumière de Sa grâce. »

# Q3. Retour à Krezk
À leur arrivée à Krezk, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-baroness-anna-krezkova">Anna Krezkova</a>, qui attend anxieusement le retour de <a href="../Appendices/Non-Player%20Characters.md#en-baron-dmitri-krezkov">Dmitri</a>, accueille les joueurs à la porte. Lorsqu'il revient, elle l'embrasse, reconnaissante de le retrouver sain et sauf, et remercie sincèrement les joueurs d'avoir fait le déplacement.

<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-baroness-anna-krezkova">Anna</a> et <a href="../Appendices/Non-Player%20Characters.md#en-baron-dmitri-krezkov">Dmitri</a> sont deux **<a href="https://www.aidedd.org/dnd/monstres.php?vf=noble">nobles</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-noble-monstre"><sup>fiche</sup></a>** dotés d'une Force de 14 (+2), qui manient respectivement une ***hache d'armes argentée*** et une ***épée longue*** (+4 au toucher, 1d10 + 2 dégâts tranchants chacune). Ils accompagnent volontiers les joueurs à l'abbaye s'ils le leur demandent, mais les avertissent, embarrassés, qu'ils ne seront probablement pas d'une grande aide au combat.

> [!abstract]+ **L'aide d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a>**
> Si <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a> est présent, les joueurs peuvent le convaincre de les aider à affronter <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> en invoquant ses obligations de beau-frère des Krezkov et en réussissant un test de Charisme (Persuasion) DD 10. (Au départ, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a> ne se sent aucune obligation de les aider. Il méprise la « lâcheté » de <a href="../Appendices/Non-Player%20Characters.md#en-baron-dmitri-krezkov">Dmitri</a> et sa « résignation » face à la malédiction familiale, ainsi que ses efforts pour éloigner <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zuleika-toranescu">Zuleika</a> d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a> et lui faire honte de sa lycanthropie.)
>
> Les joueurs effectuent ce test avec avantage s'ils affirment que <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zuleika-toranescu">Zuleika</a> voudrait qu'il aide son frère. Ils réussissent automatiquement s'ils expliquent à <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a> que <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> a pris l'apparence de sa femme, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zuleika-toranescu">Zuleika</a>, pour pousser <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-ilya-krezkov">Ilya</a> à tuer <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-kala-krezkova">Kala</a>, la nièce d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a>.

## Q3a. Retour à l'abbaye
Tandis que les joueurs gravissent la <span class="citation">S5. Route sinueuse (p. 147)</span>, l'étincelle divine contenue dans l'*<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-campagne-icon-of-dawns-grace">Icône de la Grâce de l'Aube</a>* leur adresse la parole. Elle leur demande :

* ce qu'est devenue l'abbaye de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a> après la mort de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">Markovia</a> au château Ravenloft ;
* comment <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> est venu s'installer dans l'abbaye, à Krezk ;
* ce qu'est devenu <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> après son arrivée à l'abbaye et comment il a sombré dans la folie.

Quelles que soient leurs réponses, l'étincelle les avertit que <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>, comme toutes les créatures d’origine céleste, sera probablement zélé, inflexible et entièrement dévoué à ce qu'il croit être sa mission. « Avancez avec prudence et préparez vos armes, murmure-t-elle par télépathie. Car les rayons du <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-morninglord">Seigneur de l'Aube</a> ne font que briller plus vivement lorsqu'ils perçoivent les ténèbres devant eux. »
<a id="en-the-north-gate" data-traduction="ancre"></a>
### La porte nord
À la <span class="citation">S6. Porte nord (p. 147)</span>, les joueurs sont accueillis par <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-otto-belview">Otto</a> et <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zygfrek-belview">Zygfrek Belview</a>. S'ils ont accepté d'enquêter sur la « perfection » de <a href="../Appendices/Non-Player%20Characters.md#en-cyrus-belview">Cyrus</a> dans [Arc K : L'abbaye déchue](Arc%20K%20-%20The%20Fallen%20Abbey.md#en-the-eavesdroppers), <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-otto-belview">Otto</a>, surexcité, et <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zygfrek-belview">Zygfrek</a>, anxieuse, leur demandent s'ils l'ont vu depuis leur départ de l'abbaye et comment la « perfection » de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> l'a transformé. « Est-il fort ? » brait joyeusement <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-otto-belview">Otto</a>. « Est-il beau ? » murmure <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zygfrek-belview">Zygfrek</a> d'une voix tremblante.

Si les joueurs révèlent la vérité sur <a href="../Appendices/Non-Player%20Characters.md#en-cyrus-belview">Cyrus</a>, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-otto-belview">Otto</a> et <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zygfrek-belview">Zygfrek</a> sont horrifiés. <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zygfrek-belview">Zygfrek</a> se tait et serre son manteau autour d'elle, tandis qu'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-otto-belview">Otto</a> exige avec colère qu'ils retirent leur « mensonge ». « <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">L'Abbé</a> ne nous mentirait jamais ! » hurle-t-il, des larmes au coin des yeux.

Les joueurs peuvent convaincre <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-otto-belview">Otto</a> et <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zygfrek-belview">Zygfrek</a> de leur sincérité en réussissant un test de Charisme (Persuasion) DD 10. Ils réussissent automatiquement s'ils décrivent l'apparence ou la personnalité de <a href="../Appendices/Non-Player%20Characters.md#en-cyrus-belview">Cyrus</a>, ou d'autres détails qu'ils ne peuvent connaître qu'en l'ayant rencontré. <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-otto-belview">Otto</a> et <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zygfrek-belview">Zygfrek</a> s'effondrent alors, le cœur brisé. « Nous attendons depuis si longtemps, marmonne <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-otto-belview">Otto</a> en reniflant. Qu'allons-nous attendre, à présent ? » Pendant ce temps, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zygfrek-belview">Zygfrek</a> rabat sa capuche sur son visage, quitte la porte et s'assied au bord de la falaise pour contempler le village en contrebas avec tristesse, honte et dégoût d'elle-même. Tous deux sont reconnaissants des conseils et encouragements des joueurs.

<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-otto-belview">Otto</a> et <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zygfrek-belview">Zygfrek</a> conduisent volontiers les joueurs auprès de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> si on le leur demande ; cependant, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zygfrek-belview">Zygfrek</a> préfère rester près de la falaise si on lui a révélé la duplicité de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>.
<a id="en-the-courtyard" data-traduction="ancre"></a>
### La cour
En entrant dans la <span class="citation">S12. Cour (p. 150)</span>, les joueurs rencontrent <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-clovin-belview">Clovin Belview</a>, qui apporte des bols de bouillie froide aux Belview enfermés dans les remises en pierre cadenassées. Il les salue et leur apprend que <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> est à l'asile, en <span class="citation">S15. Maison de fous (p. 151)</span>, où il prend soin de sa famille et lui prodigue un soutien spirituel.

Si les joueurs ont accepté d'enquêter sur la « perfection » de <a href="../Appendices/Non-Player%20Characters.md#en-cyrus-belview">Cyrus</a> dans [Arc K : L'abbaye déchue](Arc%20K%20-%20The%20Fallen%20Abbey.md#en-the-eavesdroppers), <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-clovin-belview">Clovin</a> leur demande avec empressement s'ils l'ont vu depuis leur départ de l'abbaye. « Va-t-il bien ? » demande-t-il, avant d'ajouter : « S'est-il habitué à sa nouvelle forme ? »

Si les joueurs révèlent la vérité sur <a href="../Appendices/Non-Player%20Characters.md#en-cyrus-belview">Cyrus</a>, le visage de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-clovin-belview">Clovin</a> se décompose un instant, puis devient froid et soigneusement impassible. « Je vois », répond-il, tandis que la tête de nourrisson sur son épaule se met à pleurer.

Malgré sa déception, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-clovin-belview">Clovin</a> entend tenir sa promesse si les joueurs apportent des nouvelles de <a href="../Appendices/Non-Player%20Characters.md#en-cyrus-belview">Cyrus</a>. Avant de les conduire à <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>, il les mène alors à un support en bois recouvert d'un drap noir, dans l'angle sud-est du <span class="citation">S17. Grenier et beffroi (p. 152)</span>. Deux paires d'ailes ayant les propriétés de *<a href="https://www.aidedd.org/dnd/om.php?vf=cape-de-vol">capes de vol</a>*, à l'armature en os d'animaux, y sont suspendues. (<a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">L'Abbé</a> les a fabriquées lors de ses premières expériences sur <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-the-belviews">les Belview</a>, mais les a abandonnées depuis longtemps.) Elles présentent les différences suivantes :

* Ce sont des ailes artificielles, plutôt que des capes ; une fois activées, elles s'animent au lieu de se transformer.
* Une paire d'ailes s'anime pendant 1 minute au lieu de 1 heure.
* Une fois qu'un jeu d'ailes a servi, il ne peut plus être utilisé jusqu'à l'aube suivante.
* Une paire ressemble à des ailes d'oiseau et porte des centaines de grandes plumes duveteuses arrachées à la forme d'<a href="https://www.aidedd.org/dnd/monstres.php?vf=aigle-geant">aigle géant</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-giant-eagle-monstre"><sup>fiche</sup></a> de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>. L'autre ressemble à des ailes de chauve-souris, avec de longues membranes en peau animale tannée.
* Une créature peut s'harmoniser avec ces ailes en 1 minute.
<a id="en-q3b-confronting-the-abbot" data-traduction="ancre"></a>
## Q3b. Confronter l'Abbé
Les joueurs peuvent trouver <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> dans l'asile de l'abbaye, qui correspond dans l'ensemble à la description de la <span class="citation">S15. Maison de fous (p. 151)</span>. Toutefois, les cellules des Belview comportent des barreaux de fer qui leur permettent d'assister à la scène. En s'approchant et en entrant dans la zone, les joueurs surprennent la conversation suivante :

<div class="description">
<p>Un beau jeune homme vêtu d'une robe de moine se tient à mi-chemin du couloir, un livre de prières sous le bras : <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>. Devant lui, une femme délicate dans une robe déchirée garde la tête baissée en signe d'acquiescement silencieux : <a href="../Appendices/Non-Player%20Characters.md#en-vasilka">Vasilka</a>. Le <a href="https://www.aidedd.org/dnd/monstres.php?vf=golem-de-chair">golem de chair</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-flesh-golem-monstre"><sup>fiche</sup></a> se tient derrière eux ; sa silhouette grotesque les domine dans l'ombre.</p>
<p>« Je t'ai dit de ne pas te souiller au contact des impurs, la réprimande <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> d'une voix dure. Surtout pas aujourd'hui. Aurais-tu oublié l'opération que tu dois subir ce soir ? La moindre parcelle de corruption de ces créatures pourrait damner la contrée que tu es censée servir. »</p>
<p>« Je suis désolée, murmure <a href="../Appendices/Non-Player%20Characters.md#en-vasilka">Vasilka</a> en tremblant. Je ne pensais pas… »</p>
<p>« Non, répond froidement <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>. Tu ne pensais pas. »</p>
</div>

À moins que les joueurs ne l'interrompent, la conversation se déroule comme suit :

* <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">L'Abbé</a> soupire, se masse les tempes et pose une main paternelle sur l'épaule de <a href="../Appendices/Non-Player%20Characters.md#en-vasilka">Vasilka</a>. « Ne crains rien, dit-il doucement. Le pardon et la grâce du <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-morninglord">Seigneur de l'Aube</a> sont éternels, pourvu que nous nous souvenions de la place qui nous revient. »
* <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">L'Abbé</a> désigne le <a href="https://www.aidedd.org/dnd/monstres.php?vf=golem-de-chair">golem de chair</a> et <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-the-belviews">les Belview</a> dans leurs cellules, puis ajoute : « La leur est ici. Et la tienne est… ? »
* <a href="../Appendices/Non-Player%20Characters.md#en-vasilka">Vasilka</a> baisse davantage la tête et répond : « Dans la grande salle, à attendre mes noces. »
* <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">L'Abbé</a> sourit, acquiesce et lui serre l'épaule. « Bien. Tant que tu t'en souviendras, tu ne pourras pas t'égarer. »

<a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">L'Abbé</a> se tourne alors vers les joueurs et les salue chaleureusement. Il leur souhaite la bienvenue à l'abbaye de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a> et s'enquiert de la raison de leur venue. S'ils insistent pour qu'il épargne <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-baroness-anna-krezkova">Anna</a> et renonce à prendre son cœur, il rit doucement et les réprimande gentiment, observant que « les voies des dieux peuvent sembler insensibles, voire cruelles, aux profanes, mais la foi nous guidera toujours vers le salut ».

> [!abstract]+ **Révéler la vérité**
> Si les joueurs reprochent à <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> ses mensonges aux Belview au sujet de <a href="../Appendices/Non-Player%20Characters.md#en-cyrus-belview">Cyrus</a> et de la promesse de « perfection », <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-the-belviews">les Belview</a> dans leurs cellules font silence. Le visage de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> se ferme et il demande froidement aux joueurs d'où leur viennent ces « fables ».
> 
> Quelle que soit leur réponse, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> se tourne vers <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-the-belviews">les Belview</a> dans leurs cellules et déclare : « Ne laissez pas ces étrangers vous égarer. Avec le <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-morninglord">Seigneur de l'Aube</a>, tout est possible. » <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-the-belviews">Les Belview</a> se mettent alors à hurler et à grincer des dents, martelant les barreaux et exigeant que ces « étrangers crasseux et menteurs » soient « égorgés, écartelés et cuits en ragoût ».
> 
> Les joueurs peuvent calmer <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-the-belviews">les Belview</a> et les convaincre de la vérité en réussissant un test de Charisme (Persuasion) DD 20. Le DD passe à 10 s'ils mettent d'abord <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> au défi de dire aux Belview s'il peut les « parfaire ». (Incapable de mentir, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> refuse de répondre et se contente d'affirmer que « son troupeau » connaît les paroles de son « berger » et lui fait confiance.) Si <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-otto-belview">Otto</a>, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zygfrek-belview">Zygfrek</a> ou <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-clovin-belview">Clovin</a> sont présents, les joueurs réussissent automatiquement : leurs compagnons reprochent ses « mensonges » à <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> et proclament devant leur famille que <a href="../Appendices/Non-Player%20Characters.md#en-cyrus-belview">Cyrus</a> n'a pas été « parfait » et que <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> n'a aucun moyen d'achever leur transformation.

Si les joueurs présentent l'*<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-campagne-icon-of-dawns-grace">Icône de la Grâce de l'Aube</a>* et lui expliquent que son âme a été corrompue et doit être restaurée au moyen de l'*Icône*, le visage de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> se glace. Il les avertit doucement qu'ils « prononcent les paroles de faux prophètes ». « Cet artefact est resté des siècles dans le château du <a href="https://www.aidedd.org/dnd/monstres.php?vf=vampire">vampire</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-vampire-monstre"><sup>fiche</sup></a>, déclare-t-il. Rejetez-le et extirpez de vos esprits les poisons qu'il y a instillés. »

Si les joueurs insistent pour purifier l'âme de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> ou continuent de le contester, il plisse les yeux et exige d'une voix douce qu'ils quittent immédiatement l'abbaye, « avant d'abuser de son hospitalité ». Lisez :

<div class="description">
<p>Une tension palpable emplit l'air tandis que les ombres de la pièce s'épaississent. Sol et murs semblent vibrer de puissance, et les yeux de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> brillent brièvement d'une folie dorée.</p>
</div>

***Vasilka intervient.*** Si les joueurs refusent de partir et ont remis la guirlande de <a href="../Appendices/Non-Player%20Characters.md#en-vasilka">Vasilka</a> au **<a href="https://www.aidedd.org/dnd/monstres.php?vf=golem-de-chair">golem de chair</a>** dans [Arc K : L'abbaye déchue](Arc%20K%20-%20The%20Fallen%20Abbey.md#en-vasilkas-lesson), elle s'interpose entre <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> et eux et le supplie de ne pas leur faire de mal. « Ils sont courageux, bons et sages, dit-elle d'une voix tremblante. Ce ne serait sûrement pas une folie de les écouter ? »

À moins que les joueurs ne l'interrompent, l'échange suivant se produit :

* <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">L'Abbé</a> ordonne à <a href="../Appendices/Non-Player%20Characters.md#en-vasilka">Vasilka</a> : « Écarte-toi, sotte créature. Ne laisse pas leurs paroles troubler ton esprit et te faire oublier tes devoirs. »
* <a href="../Appendices/Non-Player%20Characters.md#en-vasilka">Vasilka</a> secoue silencieusement la tête. Le visage de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> s'assombrit et il lui demande si elle le défie. Elle hésite, puis acquiesce lentement, des larmes coulant de ses yeux.
* Une ombre passe sur le visage de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> et il plisse les yeux. « Alors tu es défectueuse, et il faut se débarrasser de toi. » Lisez :

<div class="description">
<p>La main de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> jaillit, saisit <a href="../Appendices/Non-Player%20Characters.md#en-vasilka">Vasilka</a> à la gorge et la soulève dans les airs. Un voile d'ombres radieuses tourbillonne dans sa paume, puis se condense en une <a href="https://www.aidedd.org/regles/equipement/armes/">masse d'armes</a> en platine aux cruels reflets. « Peut-être ai-je été trop patient avec toi, déclare-t-il d'une voix sans vie. Trop compatissant. Je peux toujours recommencer, avec de meilleures pièces et une meilleure éducation. »</p>
</div>

À moins que les joueurs l'en empêchent, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> agrippe <a href="../Appendices/Non-Player%20Characters.md#en-vasilka">Vasilka</a>, qui ne résiste pas, et la traîne dans la cour, où il l'attaque avec sa ***masse d'armes***. (Voir ci-dessous pour davantage d'informations sur l'attaque de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>.)

***L'insoumission des joueurs.*** Si les joueurs refusent de partir et n'ont pas remis la guirlande de <a href="../Appendices/Non-Player%20Characters.md#en-vasilka">Vasilka</a> au **<a href="https://www.aidedd.org/dnd/monstres.php?vf=golem-de-chair">golem de chair</a>** dans [Arc K : L'abbaye déchue](Arc%20K%20-%20The%20Fallen%20Abbey.md#en-vasilkas-lesson), une ombre passe sur le visage de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> et il plisse les yeux. Lisez :

<div class="description">
<p><a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">L'Abbé</a> avance d'un pas qui résonne comme un coup de tonnerre dans le couloir assombri. Un voile d'ombres radieuses tourbillonne dans sa paume, puis se condense en une <a href="https://www.aidedd.org/regles/equipement/armes/">masse d'armes</a> en platine aux cruels reflets.</p>
<p>« Si vous refusez d'obéir, déclare-t-il, on vous y contraindra. »</p>
</div>

<a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">L'Abbé</a> passe alors à l'attaque.
<a id="en-q3c-the-abbots-rage" data-traduction="ancre"></a>
## Q3c. La rage de l'Abbé
Lorsqu'il attaque, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> se défait de sa robe de moine et se transforme, révélant sa véritable forme angélique. Lisez :

<div class="description">
<p>Une cascade éblouissante de lumière divine jaillit du corps de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>. D'immenses ailes se déploient dans son dos, chacune de leurs grandes plumes blanche comme neige et parfaitement dessinée. Ses vêtements de mortel tombent, révélant une chair blanche et lumineuse qui semble sculptée dans le marbre. Des gantelets d'or gravés de runes célestes enserrent ses avant-bras ; un sarong doré entoure souplement sa taille, son tissu fouetté par un vent tourbillonnant qui se lève.</p>
<p>Les cheveux de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> s'allongent jusqu'à ses épaules, scintillant comme de l'or filé. Sa carrure et son torse s'élargissent. Il semble se redresser, grandissant jusqu'à atteindre près de sept pieds. L'air crépite de puissance ; les murs eux-mêmes paraissent s'incliner vers lui tandis que ses yeux s'embrasent de colère céleste.</p>
</div>

Si <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> a engagé le combat en attaquant <a href="../Appendices/Non-Player%20Characters.md#en-vasilka">Vasilka</a>, il continue jusqu'à l'avoir réduite à 0 point de vie ou jusqu'à ce qu'un joueur lui inflige 20 points de dégâts au cours d'un même tour. Il se tourne alors contre les joueurs. (<a href="../Appendices/Non-Player%20Characters.md#en-vasilka">Vasilka</a> ne riposte en aucune circonstance.)

Au combat, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> préfère rester dans la cour de l'abbaye. Un joueur peut cependant l'attirer dans une aile adjacente en réussissant un test de Charisme (Représentation) DD 20.

> [!combat]- **Combat : L'Étoile déchue**  
> **Difficulté du combat** : sanglante (première phase), sanglante (deuxième phase)
> **Niveau prévu des personnages** : 7
> **Alliés :** <a href="../Appendices/Non-Player%20Characters.md#en-ireena-kolyana">Ireena Kolyana</a> (FP 2), <a href="../Appendices/Non-Player%20Characters.md#en-ezmerelda-davenir">Ezmerelda d'Avenir</a> (FP 4)
> **Perte de PV prévue :** 42% (première phase), 51% (deuxième phase), soit 93% au total
>

En deuxième phase, limitez sa réaction Queue à 2/round. Réduisez également les dégâts de son action bonus Rayon d'éclipse à 2d6 pour chaque type de dégâts. |

> Si les joueurs ont donné la guirlande de fleurs de <a href="../Appendices/Non-Player%20Characters.md#en-vasilka">Vasilka</a> au **<a href="https://www.aidedd.org/dnd/monstres.php?vf=golem-de-chair">golem de chair</a>** dans [Arc K : L'abbaye déchue](Arc%20K%20-%20The%20Fallen%20Abbey.md), celui-ci rejoint leur combat contre <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> lorsque ce dernier entre dans sa deuxième phase.

Ses caractéristiques sont alors instantanément remplacées par celles de sa seconde forme. Son rang d’initiative ne change pas, les dégâts excédentaires ne sont pas reportés sur sa nouvelle forme et il ne conserve aucun des états qui l’affectaient sous sa forme précédente. Il utilise ensuite immédiatement sa réaction de <strong><em>présence terrifiante</em></strong>.</p>
<a id="en-actions" data-traduction="ancre"></a>
<h3>Actions</h3>
<p><strong><em>Attaques multiples.</em></strong> <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> effectue deux attaques. Il peut remplacer l’une de ces attaques par <strong><em>rayon de lumière</em></strong>.</p>
<p><strong><em>Masse d'armes.</em></strong> <em>Attaque au corps à corps avec une arme :</em> +9 au toucher, allonge 5 pieds, une cible. Touché : 7 (1d6 + 4) dégâts contondants plus 4 (1d8) dégâts radiants.</p>
<p><strong><em>Rayon de lumière.</em></strong> <em>Attaque de sort à distance :</em> +10 au toucher, portée 30 pieds, une cible. <em>Touché :</em> La cible subit 9 (2d8) dégâts radiants et sa silhouette est soulignée d’une lumière radiante jusqu’à la fin du prochain tour d’<a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a>. Les jets d’attaque contre une créature ou un objet affecté bénéficient d’un avantage si l’attaquant peut voir sa cible, et la créature ou l’objet affecté ne peut pas bénéficier de l’invisibilité.</p>
<p><strong><em>Contact guérisseur (5/jour).</em></strong> <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> touche une autre créature. La cible récupère magiquement 23 (4d8 + 5) points de vie et est libérée de toute malédiction, maladie, poison, cécité ou surdité.</p>
<p><strong><em>Changement de forme.</em></strong> <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> se transforme magiquement en un humanoïde ou une bête dont le facteur de puissance est inférieur ou égal au sien, ou reprend sa véritable forme. Il retrouve sa véritable forme s’il est réduit à 0 point de vie. L’équipement qu’il porte ou tient est absorbé par la nouvelle forme ou porté par elle, au choix d’<a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a>. Sous une nouvelle forme, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> conserve ses caractéristiques de jeu et la capacité de parler, mais sa CA, ses modes de déplacement, sa Force, sa Dextérité et ses sens spéciaux sont remplacés par ceux de la nouvelle forme. Il acquiert également les caractéristiques et capacités que possède la nouvelle forme et qu’il ne possède pas, à l’exception des aptitudes de classe, des actions légendaires et des actions d’antre.</p>
<a id="en-bonus-actions" data-traduction="ancre"></a>
<h3>Actions bonus</h3>
<p><strong><em>Vent divin.</em></strong> <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> déchaîne une violente rafale avec ses ailes angéliques dans un cône de 10 pieds. Chaque créature dans cette zone doit réussir un jet de sauvegarde de Constitution DD 17 sous peine de subir 14 (4d6) dégâts tranchants et d’être repoussée de 10 pieds.</p>
<p><strong><em>Radiance sacrée (1/jour).</em></strong> Le corps d'<a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> éclate de lumière divine. Chaque créature située à 20 pieds ou moins qui peut le voir doit réussir un jet de sauvegarde de Constitution DD 18 sous peine de subir 14 (4d6) dégâts radiants. Une créature qui rate le jet de 5 ou plus est également aveuglée jusqu'au début du prochain tour d'<a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a>. Une créature qui rate le jet de 10 ou plus est également charmée par <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> jusqu'au début du prochain tour d'<a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a>. Tant qu'elle est ainsi charmée, elle doit tomber à terre pour se prosterner devant lui au début de son tour, puis terminer immédiatement son tour.</p>
<a id="en-reactions" data-traduction="ancre"></a>
<h3>Réactions</h3>
<p><a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> peut effectuer jusqu’à trois réactions par round, mais une seule par tour. Si un effet ou un état devait empêcher ses réactions, une seule réaction est perdue à la place.</p>
<p><strong><em>Indomptable.</em></strong> <strong>Déclencheur :</strong> Une créature hostile termine son tour. <strong>Effet :</strong> <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> peut réitérer le jet de sauvegarde contre un effet ou un état qui l’affecte actuellement. (Cette réaction est sans effet si l’effet ou l’état ne nécessitait pas, à l’origine, de rater un jet de sauvegarde.)</p>
<p><strong><em>Châtiment.</em></strong> Lorsqu'un ennemi le rate avec une attaque au corps à corps, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> effectue l'attaque suivante contre lui : <strong><em>Paume.</em></strong> <em>Attaque au corps à corps avec une arme</em> : +9 au toucher, allonge 5 pieds, une cible. Touché : 7 (1d6 + 4) dégâts contondants, et <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> peut contraindre la cible à effectuer un jet de sauvegarde de Force DD 17. En cas d'échec, la cible est repoussée d'un maximum de 10 pieds ou agrippée (évasion DD 17). S'il agrippe la cible, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> peut immédiatement utiliser sa <strong><em>descente</em></strong>.</p>
<p><strong><em>Descente.</em></strong> Lorsqu'il agrippe un ennemi, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> peut immédiatement voler d'une distance maximale égale à sa vitesse en l'entraînant avec lui. S'il passe à 5 pieds ou moins du sol au cours de ce déplacement, l'ennemi agrippé doit réussir un jet de sauvegarde de Force DD 17 sous peine de subir 3 (1d6) dégâts contondants par tranche de 10 pieds descendue. Pour chaque tranche supplémentaire de 5 pieds parcourue par <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> le long du sol, l'ennemi agrippé subit 2 (1d4) dégâts contondants supplémentaires tandis qu'<a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> le traîne contre terre. (Ce déplacement ne provoque pas d'attaques d'opportunité.) À la fin du déplacement d'<a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a>, l'ennemi agrippé est jeté à terre.</p>
<p><strong><em>Ascension.</em></strong> En réaction aux dégâts subis, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> relâche toutes les créatures qu’il agrippe, puis vole d’une distance maximale égale au tiers de sa vitesse sans provoquer d’attaques d’opportunité.</p>
<p><strong><em>Transformation (coûte 2 réactions).</em></strong> Lorsqu’il subit l’un des états suivants, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> prend momentanément la forme de la bête correspondante et met fin à cet état : aveuglé (<a href="https://www.aidedd.org/dnd/monstres.php?vf=chauve-souris-geante">chauve-souris géante</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-giant-bat-monstre"><sup>fiche</sup></a>), agrippé (<a href="https://www.aidedd.org/dnd/monstres.php?vf=pieuvre">pieuvre</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-octopus-monstre"><sup>fiche</sup></a>), paralysé (<a href="https://www.aidedd.org/dnd/monstres.php?vf=serpent-venimeux-geant">serpent venimeux géant</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-giant-poisonous-snake-monstre"><sup>fiche</sup></a>), à terre (<a href="https://www.aidedd.org/dnd/monstres.php?vf=araignee-geante">araignée géante</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-giant-spider-monstre"><sup>fiche</sup></a>), entravé (souris) ou étourdi (méduse). <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> reprend ensuite immédiatement sa véritable forme.</p>
</div>

<a id="en-the-abbots-redemption" data-traduction="ancre"></a>
### La rédemption de l'Abbé
Lorsque les joueurs réduisent à 0 les points de vie de la deuxième phase de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>, lisez :

<div class="description">
<p>La bête rugit, sa terrible silhouette se tordant de spasmes. Puis, dans un dernier hurlement strident, elle s'écroule au sol et s'immobilise.</p>
</div>

Peu après la défaite de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>, si l'*<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-campagne-icon-of-dawns-grace">Icône de la Grâce de l'Aube</a>* est présente, l’âme de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l’Abbé</a> y réagit.

<div class="description">
<p>De petites particules de lumière dorée se mettent à scintiller sur le corps immobile de la bête. Lentement, elles se rassemblent pour former un globe de flammes dorées qui flotte au-dessus de la poitrine de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>.</p>
</div>

L'*<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-campagne-icon-of-dawns-grace">Icône de la Grâce de l'Aube</a>* se met à briller d'une lumière dorée. L'étincelle divine qu'elle contient demande aux joueurs de mettre l'*Icône* au contact du globe. « Il a beaucoup souffert et s'est perdu dans les brumes et les ombres, dit-elle tristement. Mais peut-être n'est-il pas encore perdu à jamais. »

Si les joueurs mettent l'*Icône* au contact du globe, leurs esprits sont transportés dans un demi-plan à l'intérieur de l'âme de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>. Lisez :

<div class="description">
<p>Vous clignez des yeux. Lorsque vous les rouvrez, l'abbaye a disparu autour de vous. À sa place, un vide sombre et infini s'étend dans toutes les directions. Son sol est couvert d'une nappe de brume doucement mouvante, et seuls des sanglots lointains troublent son silence. Près de vous, un globe de flammes dorées flotte paisiblement.</p>
</div>

Le globe contient l'étincelle divine qui habite l'*Icône*. Il suit les joueurs dans leurs déplacements et peut communiquer avec eux par télépathie. Il leur explique que, s'ils trouvent <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> et le persuadent de s'unir de nouveau à lui, il pourra lui rendre sa gloire d'antan et purifier son âme de toute corruption.

Les joueurs peuvent suivre les sanglots jusqu'à <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>. Lisez :

<div class="description">
<p>Les sanglots proviennent d'une silhouette pâle et décharnée assise au sol non loin de là : un jeune homme. Sa robe de moine est usée et déchirée ; ses joues sont rouges et marbrées sous le mince bandeau de brume qui recouvre ses yeux.</p>
<p>Deux ailes autrefois majestueuses pendent mollement à ses côtés, leurs plumes ternes, effilochées et décolorées. Deux entraves forgées de brume les retiennent au sol, et une sombre nuée d'ombres s'accroche à lui comme un linceul.</p>
</div>

Les joueurs reconnaissent l'apparence mortelle habituelle de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>. En approchant, ils l'entendent murmurer sans cesse : « Je vous ai failli. » Il serre ses genoux contre sa poitrine et se balance d'avant en arrière, des larmes s'échappant de sous le bandeau de brume qui recouvre ses yeux.

<a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">L'Abbé</a> pense avoir failli au <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-morninglord">Seigneur de l'Aube</a> et perdu sa grâce ; il se croit donc damné. Si les joueurs le saluent, il se retourne avec effroi et exige qu'ils « se montrent », car « ils marchent dans les ténèbres et il ne peut pas les voir ».

Si les joueurs lui disent qu'il a les yeux bandés, il reste un instant interdit, puis secoue la tête. « Je vois, murmure-t-il. Je suis donc damné. Allez-vous-en, et ne vous souciez plus de ma misère. »

Si les joueurs demandent à <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> de s'unir de nouveau à l'étincelle divine, il hésite, puis demande à en sentir la chaleur. S'ils invitent le globe à s'approcher de lui, il l'entoure de ses mains et se met à pleurer de joie, murmurant qu'il est « magnifique ».

À ce moment, si au moins un joueur possède une Sagesse (Perception) passive de 13 ou plus, ajoutez :

<div class="description">
<p>Le linceul d'ombre se resserre encore autour de lui. Vous comprenez qu'il ne s'agit pas d'une ombre unique, mais d'innombrables silhouettes indistinctes et informes qui se superposent. Elles chuchotent à ses oreilles ; leurs voix froides et creuses résonnent dans le vide.</p>
</div>

<a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">L'Abbé</a> s'interrompt, puis recule précipitamment, s'éloignant du globe avec un cri d'effroi. Tout joueur dont la Sagesse (Perception) passive est de 14 ou plus voit alors un nuage de brume voisin prendre brièvement la forme d'un visage de femme, avant que des ombres tourbillonnantes le déchirent. Un joueur qui a vu ce visage et dont la Sagesse (Perspicacité) passive atteint 15 discerne son expression de chagrin et d'inquiétude : la femme semblait appeler.

Un joueur qui interroge <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>, ou dont la Sagesse (Perspicacité) passive atteint 13, apprend que <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> ne perçoit pas les murmures et ignore même leur présence. Un joueur qui s'approche de lui ou réussit un test de Sagesse (Perception) DD 15 distingue quelques mots et phrases dans la cacophonie :

* « La lumière t'a abandonné, comme tu l'as abandonnée. »
* « Leurs mensonges sont réconfortants, mais ils restent des mensonges. »
* « Tu as mérité ta damnation. Tu le sais. »

Si les joueurs le confrontent, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> répond d'une voix tremblante : « Il est trop tard. J'ai trahi ma mission et renié ma grâce. Je ne peux retrouver le chemin de la lumière, et le <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-morninglord">Seigneur de l'Aube</a> ne voudrait pas de moi, même si j'y parvenais. »

> [!lore]+ **Sombres murmures**
> Les ombres murmurantes sont une manifestation des [Sombres Puissances](../Chapter%202%20-%20The%20Land%20of%20Barovia/Lore%20of%20Barovia.md#en-dark-powers). Elles ont entraîné l'âme de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> vers le mal, il y a longtemps, pour l'empêcher de défier <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-strahd-von-zarovich">Strahd</a> ou de guérir la contrée de sa corruption.

Lorsque <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> termine sa protestation, un autre nuage de brume, à faible distance du premier, se dresse brièvement sous la forme d'une silhouette féminine en robe, avant d'être déchiré par les ombres tourbillonnantes. Un joueur dont la Sagesse (Perception) passive est de 13 ou plus discerne qu'elle semblait tendre la main vers les joueurs et les appeler. Un joueur qui a vu le visage et dont la Sagesse (Perspicacité) passive atteint 13 y discerne une expression de chagrin et d'inquiétude.

Lorsque la silhouette disparaît, une carte de tarokka descend en flottant du vide et se pose devant l'un des joueurs. Si quelqu'un l'examine, lisez :

<div class="description">
<p>Cette carte de tarokka est le quatre de glyphes : la Bergère. Elle représente une femme d'âge mûr vêtue d'une simple robe blanche, au milieu d'un troupeau de moutons, sur une colline devant le soleil levant.</p>
</div>

Si on lui montre la carte, <a href="../Appendices/Non-Player%20Characters.md#en-ezmerelda-davenir">Ezmerelda</a> trouve « étrange » que la Bergère soit représentée devant un soleil levant. « Ce genre de symbole conviendrait davantage à la carte du Prêtre, songe-t-elle. Et la Bergère est généralement jeune ; parmi les glyphes, seuls le Missionnaire et l'Évêque sont traditionnellement représentés âgés. »

> [!lore]+ **La Bergère**
> La carte de tarokka est un message envoyé par l'esprit de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a>. Incapable de pénétrer seule dans l'âme de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>, elle espère que les joueurs l'invoqueront pour qu'elle puisse lui parler en leur faveur.

Les joueurs peuvent convaincre <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> de s'unir de nouveau à l'étincelle divine en avançant tout argument raisonnable, par exemple en réfutant directement les murmures des <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-dark-powers">Sombres Puissances</a> ou en évoquant la séance de spiritisme de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a>, ou encore en réussissant un test de Charisme (Persuasion) DD 15.

> [!abstract]+ **Échec de la rédemption**
> Si les joueurs tentent ici de persuader <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> sans avoir d'abord invoqué <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a> et échouent, l'obscurité devient plus profonde et plus oppressante. <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">L'Abbé</a> se replie encore sur lui-même et ses ailes semblent se flétrir et se craqueler. « Ne voyez-vous pas ? murmure-t-il d'une voix à peine audible. Même vous ne pouvez nier ma damnation. Tout est fini. »
>
> Les ombres murmurantes se renforcent. Le globe doré se met à vaciller et à faiblir, et la brume commence à encercler le corps de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> ; elle l'engloutit entièrement en deux rounds. Tant que la brume monte, le DD de tout nouveau test de Charisme (Persuasion) pour convaincre <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> passe à 20.
>
>Les joueurs peuvent faire reculer la brume en convainquant <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> de s'unir de nouveau à l'étincelle ou en utilisant la carte de la Bergère pour invoquer l'esprit de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a> (voir ci-dessous). S'ils n'y parviennent pas avant que la brume engloutisse son corps, ils disparaissent du vide et réapparaissent dans l'abbaye de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a>, où le cadavre de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> se dissipe rapidement en brume.

Les joueurs peuvent aussi utiliser la carte pour invoquer l'esprit de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a>. (Aucune cérémonie ni incantation particulière n'est nécessaire : il suffit de l'appeler en prononçant son nom, la carte à la main.) S'ils le font, lisez :

<div class="description">
<p>Les ténèbres s'agitent avec fureur et le vide se tord sous cette intrusion soudaine… puis tout se calme et retombe dans le silence.</p>
<p>Une femme apparaît derrière vous. Elle porte une simple robe blanche nouée par une corde ordinaire. Son visage commence à se rider et ses cheveux bruns à grisonner, mais son regard est plein de bonté et de force.</p>
<p>« Vous m'avez appelée ? » demande-t-elle.</p>
</div>

<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">Markovia</a> salue chaleureusement les joueurs et les remercie de l'avoir invoquée. Elle peut leur communiquer les informations suivantes s'ils l'interrogent :

* L'ange que les joueurs appellent « <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> » comptait autrefois parmi les plus grands serviteurs du <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-morninglord">Seigneur de l'Aube</a>. C'est lui qui l'a choisie comme prophétesse du <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-morninglord">Seigneur de l'Aube</a>.
* Voir <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> réduit à cet état lui brise le cœur, mais elle est reconnaissante des efforts des joueurs pour le sauver. « Il a péché, murmure-t-elle, mais seulement parce qu'il était perdu dans les brumes. Les sombres puissances qui règnent sur cette contrée ont obscurci son esprit et l'ont détourné de sa véritable voie. Grâce à vous, il a l'occasion de redevenir lui-même. » (<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">Markovia</a> ne sait rien d'autre des « sombres puissances » qui règnent sur la Barovie, si ce n'est qu'elles ne sont pas <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-strahd-von-zarovich">Strahd</a> et qu'elles contrôlent <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-the-mists">les Brumes</a> ou sont elles-mêmes <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-the-mists">les Brumes</a>.)

Si les joueurs le permettent, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">Markovia</a> s'approche de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>. Lisez :

<div class="description">
<p>« <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> », dit-elle. Ce nom résonne comme une cloche dans les ténèbres. Les ombres se recroquevillent à chacun de ses pas vers lui. « Je suis là. »</p>
</div>

À moins que les joueurs les interrompent, l'échange suivant a lieu :

* <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">L'Abbé</a> se retourne brusquement au son de la voix de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">Markovia</a>. « <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">Markovia</a> ? dit-il faiblement, la voix brisée. Je t'en prie… ne me regarde pas. Je suis souillé et brisé. »
* <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">Markovia</a> s'approche et pose un genou à terre près de lui. « Ne l'étais-je pas aussi quand tu m'as trouvée ? répond-elle doucement. Perdue, brisée, désespérée ? »
* « Mon devoir était de te guider, murmure <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>. Un devoir que j'ai abandonné. »
* « Chut, mon vieil ami », dit <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">Markovia</a>. Elle pose une main sur son épaule et il se raidit. « N'est-ce pas toi qui m'as dit autrefois que nous étions destinés à être égaux devant le divin ?^[Inspiré de *<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-campagne-high-wizardry">Haute sorcellerie</a>*, de Diane Duane] Tu m'as jadis montré le chemin. Laisse maintenant mes amis en faire autant pour toi. »
* Les épaules de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> tremblent. Il hésite, puis acquiesce lentement. <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">Markovia</a> se tourne vers les joueurs et leur fait signe d'approcher le globe de flammes.

Que les joueurs aient invoqué <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a> ou non, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> hésite avant d'accepter le globe, puis leur demande : « J'ai menacé vos amis. J'ai cherché à vous faire du mal. J'ai séparé des parents de leurs enfants et abusé de la foi de ceux qui me faisaient confiance. Comment pouvez-vous m'offrir cette seconde chance en sachant ce que j'ai fait ? »

Si les joueurs lui offrent leur pardon ou indiquent autrement qu'ils le croient digne d'une seconde chance, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> reprend le globe de flammes dans ses mains. Lisez :

<div class="description">
<p>La flamme vacillante éclaire le visage de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> d'une lueur chaude et joyeuse. En un instant, la brume brûle et disparaît de ses yeux, révélant des traits redevenus juvéniles, libérés de toute ride d'inquiétude ou de peur. Une lumière dorée danse dans son regard ; elle est emplie d'espoir et d'émerveillement, plutôt que de folie ou de cruauté.</p>
<p>« Je vois », murmure-t-il avec ferveur. Des larmes de joie coulent sur ses joues tandis que la lumière devient plus forte, plus vive, plus <em>pure</em>. « Je peux voir ! »</p>
</div>

Le vide se dissipe alors dans un éclair de lumière blanche et les joueurs se retrouvent à l'abbaye de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a>.
<a id="en-the-abbots-penance" data-traduction="ancre"></a>
### La pénitence de l'Abbé
Lorsque les joueurs reviennent à l'abbaye, lisez :

<div class="description">
<p>La bête difforme étendue au sol a disparu. À sa place, un jeune homme aux ailes blanches, vêtu d'une simple robe blanche, gît immobile sur la terre.</p>
</div>

Ce jeune homme, qui ne semble pas avoir plus de dix-neuf ou vingt ans et ressemble à une version plus jeune de l'apparence mortelle habituelle de <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>, est <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> restauré. Il s'éveille si on le touche, ou de lui-même peu après le retour des joueurs.

Une fois réveillé, le jeune homme demande aux joueurs de l'appeler <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> plutôt que <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>. Il paraît un instant désorienté, tandis que l'étincelle divine intègre progressivement ses souvenirs et sa conscience de lui-même.

> [!info]+ **<a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> restauré**
> <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> utilise le profil d'un **<a href="https://www.aidedd.org/dnd/monstres.php?vf=pegase">pégase</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-pegasus-monstre"><sup>fiche</sup></a>**, avec l'aptitude **contact guérisseur** d'une **<a href="https://www.aidedd.org/dnd/monstres.php?vf=licorne">licorne</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-unicorn-monstre"><sup>fiche</sup></a>**, ainsi que la taille, les langues et l'aptitude ***changement de forme*** d'un **<a href="https://www.aidedd.org/dnd/monstres.php?vf=deva">déva</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-deva-monstre"><sup>fiche</sup></a>**. Remplacez l'attaque de ***sabots*** du <a href="https://www.aidedd.org/dnd/monstres.php?vf=pegase">pégase</a> par l'attaque suivante : ***Masse d'armes.*** *Attaque au corps à corps avec une arme :* +6 au toucher, allonge 5 pieds, une cible. *Touché* : 1d6 + 4 dégâts contondants plus 4 (1d8) dégâts radiants. <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> peut aussi lancer *<a href="https://www.aidedd.org/dnd/sorts.php?vf=rappel-a-la-vie">rappel à la vie</a>* une fois par jour, mais pas plus de trois fois par an.
>
> Lorsqu'il vient d'être restauré, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> s'éveille avec 1 point de vie et quatre niveaux d'épuisement.

Profondément reconnaissant, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> s'incline bien bas devant les joueurs pour les remercier de leur bonté et de leur miséricorde.

Si on le lui permet, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> soigne <a href="../Appendices/Non-Player%20Characters.md#en-vasilka">Vasilka</a> et lui présente de longues excuses (« Pour avoir cherché à te contrôler, t'avoir terrorisée et t'avoir imposé un rôle que tu n'as jamais désiré »). Il fait de même pour <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-the-krezkovs">les Krezkov</a> (« Pour les terribles maux que j'ai infligés à votre famille et que je ne pourrai jamais expier »), <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-the-belviews">les Belview</a> (« Pour la malédiction que j'ai infligée à votre famille, mes manipulations et mes tromperies, ma cruauté et mon insensibilité ») et les joueurs (« Pour les ombres que j'ai jetées sur vos vies et celles de vos proches »).

<a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> peut aussi communiquer les informations suivantes si on l'interroge :

* Il n'est plus tout à fait <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>, ni entièrement l'étincelle qui habitait l'*Icône*. « Je suis les deux, et pourtant aucun des deux, songe-t-il. Le même soleil qui se lève, mais sur une nouvelle aube. »
* Il compte libérer <a href="../Appendices/Non-Player%20Characters.md#en-vasilka">Vasilka</a> de ses ordres. « Elle sera libre de trouver sa propre voie, dit-il avec mélancolie, comme toutes les créatures doivent l'être. »
* Il ne compte pas davantage prendre le cœur d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-baroness-anna-krezkova">Anna Krezkova</a>. « Je ne vois pas comment cette contrée sera libérée, dit-il en baissant la tête. Mais je sais que les ténèbres ne peuvent chasser les ténèbres. Seule la lumière le peut. »
* Il ignore comment guérir <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-the-belviews">les Belview</a> de leur affliction. « Toutefois, je ferai mon possible pour soigner l'esprit de ceux que je peux aider et permettre à leur famille de se retrouver, dit-il. Avec le temps et par la grâce du <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-morninglord">Seigneur de l'Aube</a>, je trouverai la sagesse et la force de lever l'affliction que je leur ai jadis imposée. »
* Il compte rester à l'abbaye et à Krezk. « J'ai envers ces gens une dette dont je ne m'acquitterai peut-être jamais, dit-il solennellement. Ma place est ici, et je pressens que je serai bientôt appelé à défendre ceux que j'ai autrefois tourmentés. »

Avant leur départ, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> offre volontiers de soigner les joueurs avec son ***contact guérisseur*** et de les faire bénéficier de son aptitude *<a href="https://www.aidedd.org/dnd/sorts.php?vf=rappel-a-la-vie">rappel à la vie</a>* si nécessaire. « Mes pouvoirs sont très limités depuis ma renaissance, dit-il en arrachant trois plumes blanches comme neige à ses ailes, mais si vous avez vous-mêmes besoin de renaître, il vous suffira de prononcer mon nom en brandissant cette plume, et je serai là. »

> [!info]+ **L'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-campagne-icon-of-dawns-grace">Icône de la Grâce de l'Aube</a>**
> L'*<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-campagne-icon-of-dawns-grace">Icône de la Grâce de l'Aube</a>* conserve ses pouvoirs magiques, mais perd sa conscience lorsque le fragment de conscience d'<a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> est transféré à <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> racheté.

> [!info]+ **Les plumes d'<a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a>**
> Si un joueur prononce le nom d'<a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> en brandissant l'une de ses plumes, celle-ci se consume en braises radieuses. <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> vole alors jusqu'aux joueurs. Il arrive en cinq minutes s'ils se trouvent dans la partie ouest de la vallée (par exemple au Magicien des Vins, sur la colline d'Antan ou au lac Baratok), en quinze minutes s'ils sont au centre (par exemple à Vallaki, à Berez ou sur le mont Ghakis) et en trente minutes s'ils sont à l'est (par exemple au village de Barovie, au château Ravenloft ou à l'étang de Tser).
>
> Une fois appelé, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> reste seulement le temps de lancer *<a href="https://www.aidedd.org/dnd/sorts.php?vf=rappel-a-la-vie">rappel à la vie</a>* et d'offrir aux joueurs des paroles de foi et d'encouragement pour les épreuves à venir. Sur demande, il utilise aussi volontiers une ou plusieurs fois son aptitude ***contact guérisseur***.
>
> Si on lui demande de rester ou de combattre aux côtés des joueurs, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> refuse poliment, affirmant que sa place est à l'abbaye et qu'il ne peut laisser ses protégés et ses voisins sans défense. « N'ayez crainte, les rassure-t-il avant de partir. Le <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-morninglord">Seigneur de l'Aube</a> est avec vous. »

> [!profile]+ **Portrait : <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a>**
> **Interprétation**
> ***Résonance.*** <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> devrait inspirer de l'affection par sa détermination à réparer le mal qu'il a fait, du réconfort par sa profonde compassion et sa sollicitude, et de la gratitude par ses efforts sincères pour aider les joueurs.
>
> ***Émotions.*** <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> est le plus souvent pensif, triste, joyeux, coupable, honteux, inquiet, rebelle, audacieux ou serein.
>
> ***Motivations.*** <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> veut réparer le mal qu'il a fait à <a href="../Appendices/Non-Player%20Characters.md#en-vasilka">Vasilka</a>, aux Belview, aux Krezkov et aux joueurs, et défendre l'abbaye et le village de Krezk contre ceux qui leur voudraient du mal.
>
> ***Inspirations.*** Pour interpréter <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a>, inspirez-vous de Zuko (*Avatar : Le Dernier Maître de l'air*), Neji Hyûga (*Naruto*) et du père Forthill (*Les Dossiers Dresden*).
>
> **Informations sur le personnage**
> ***Personnalité.*** Aux yeux du monde, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> est un jeune homme mûr et contemplatif, profondément humble et compatissant. Avec ceux en qui il a confiance, c'est un jeune ange qui s'efforce de reconstruire son identité et de retrouver un but après sa corruption, sa défaite et sa restauration.
>
> ***Comportement au combat.*** <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> chercherait à apaiser son adversaire, mais n'hésiterait pas à défendre par la force un innocent menacé par des ennemis mal intentionnés.
<a id="en-q3d-st-markovias-gratitude" data-traduction="ancre"></a>
## Q3d. La gratitude de sainte Markovia
Lorsque les joueurs descendent pour la première fois la route en lacets et entrent à Krezk après avoir vaincu <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>, qu'ils l'aient ramené sur le droit chemin ou non, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a> les appelle au sanctuaire du Soleil blanc. Lisez :

<div class="description">
<p>Une brise chaude et agréable fait bruisser les pins. Une voix féminine, douce et bienveillante, murmure à vos oreilles : « Retrouvez-moi au sanctuaire du Soleil blanc, au bord de l'eau. Vous avez guéri ce lieu ; permettez-moi de vous apporter la guérison à mon tour. »</p>
</div>

Les joueurs qui ont parlé avec <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a> dans [La rédemption de l'Abbé](#en-the-abbots-redemption) reconnaissent sa voix.
<a id="en-markovias-gift" data-traduction="ancre"></a>
### Le don de Markovia
Si les joueurs répondent à l'invitation de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a> et se rendent au <span class="citation">S4. Bassin et sanctuaire (p. 146)</span>, lisez :

<div class="description">
<p>Lorsque vous atteignez le bord du bassin, une image apparaît dans ses eaux bleues scintillantes : une femme âgée, vêtue d'une simple robe blanche, dont les cheveux bruns ondulés commencent à grisonner. Des rides bordent ses yeux, mais l'âge n'a pas altéré la bonté et la compassion de son regard.</p>
</div>

Les joueurs qui ont eu des visions de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a> lors de la séance de spiritisme d'<a href="../Appendices/Non-Player%20Characters.md#en-ezmerelda-davenir">Ezmerelda</a> dans [Arc K : L'abbaye déchue](Arc%20K%20-%20The%20Fallen%20Abbey.md) reconnaissent son visage.

Si elle n'a pas parlé aux joueurs dans [La rédemption de l'Abbé](#en-the-abbots-redemption), <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a> se présente et les remercie d'avoir libéré l'abbaye et Krezk de « l'ombre qui pesait sur elles ». Si <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> a été vaincu sans être racheté, elle exprime son chagrin devant « la mort d'<a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a> », mais trouve du réconfort dans le fait que « son souvenir vivra dans les pierres de l'abbaye ».

<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">Markovia</a> invite chaque joueur à remplir une seule <a href="https://www.aidedd.org/regles/equipement/materiel/">gourde</a> avec l'eau du bassin. « Ces eaux étaient autrefois porteuses d'une magie bien plus grande. Elle a disparu depuis longtemps, mais votre victoire m'a permis de leur rappeler la bénédiction dont elles étaient investies, ne serait-ce que pour un temps. »

> [!item]+ **Eau du Soleil blanc**
> Au prix d'une action, un joueur peut boire tout le contenu d'une <a href="https://www.aidedd.org/regles/equipement/materiel/">gourde</a> remplie de l'eau du bassin béni. Il bénéficie immédiatement des effets d'un repos long et d'un sort de *<a href="https://www.aidedd.org/dnd/sorts.php?vf=restauration-partielle">restauration partielle</a>*.
<a id="en-cleansing-of-the-white-sun" data-traduction="ancre"></a>
### La purification du Soleil blanc
Une fois les <a href="https://www.aidedd.org/regles/equipement/materiel/">gourdes</a> remplies, si les joueurs ont ramené <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a> sur le droit chemin et qu'un joueur a reçu le don et l'état d'un vestige après avoir atteint le troisième stade de corruption d'un <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-campagne-amber-shard">éclat d'ambre</a>, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a> s'adresse personnellement à lui. Lisez :

<div class="description">
<p>« Vous portez un lourd fardeau sur vos épaules, dit-elle, cherchant à croiser votre regard de ses yeux attristés. L'avoir choisi ne le rend pas moins pesant. Si vous souhaitez rejeter le joug de la puissance à laquelle vous vous êtes enchaîné, je peux vous aider tant que la magie de l'eau perdure. »</p>
</div>

Si le joueur se montre intéressé, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">Markovia</a> l'invite à entrer dans le bassin, à prier le <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-morninglord">Seigneur de l'Aube</a>, puis à s'immerger. « Lorsque vous ressortirez de l'eau, dit-elle, votre affliction sera guérie, pourvu que vos paroles soient sincères et que vous croyiez pouvoir redevenir ce que vous étiez. »

Si le joueur ne sait quelle prière prononcer, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">Markovia</a> suggère : « Comme le soleil bannit les ténèbres de la nuit, bannissez l'ombre de mon âme et laissez la lumière m'étreindre de nouveau. »

Lorsque le joueur s'immerge après avoir prié, lisez :^[Inspiré de *Critical Role*]

<div class="description">
<p>L'eau ondule autour de vous, étouffant les bruits du monde à la surface. Vous entendez au loin le clapotis de douces vagues contre les rives et le battement du sang dans vos oreilles. Puis un murmure calme et doux résonne à travers l'eau.</p>
<p><em>« Vous vous êtes égaré, pris dans l'ombre d'un mal ancien. Ses vrilles ont semé le chaos, le désespoir et la peur dans votre esprit, laissant votre âme dans les ténèbres. »</em></p>
<p>Les battements de votre cœur résonnent à vos oreilles. Au milieu des ténèbres, vous voyez dans le vide une lueur faible et vacillante, sa surface étouffée par les vrilles d'une ombre épaisse et huileuse.</p>
</div>

Laissez au joueur un bref instant pour répondre. Qu'il le fasse ou non, poursuivez :

<div class="description">
<p><em>« Je ne peux guérir ces ténèbres, mais je peux permettre à votre lumière intérieure de les chasser, si vous acceptez de l'accueillir. »</em></p>
<p><em>« Chercherez-vous l'espoir plutôt que le désespoir, choisirez-vous le courage face à la peur et renoncerez-vous à ces ténèbres pour la lumière ? »</em></p>
</div>

Si le joueur accepte sincèrement, la voix lui répond :

<div class="description">
<p><em>« Alors ma bénédiction vous appartient, aussi longtemps que vous souhaiterez la conserver. »</em></p>
<p>La lueur dans le vide gagne en intensité. Sa surface scintille, puis <em>flamboie</em> d'une lumière pure et perçante. L'ombre hurle ; ses vrilles se tordent tandis que la lumière les consume, jusqu'à ce qu'il ne reste que la lumière, brillante et palpitante au rythme de votre cœur.</p>
</div>

Le joueur perd alors tous ses stades de corruption de l'ambre, y compris les états et dons acquis par cette corruption.

Avant le départ des joueurs, tandis que le visage de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">sainte Markovia</a> commence à s'effacer de la surface du bassin, elle avertit tout joueur purifié que l'ombre a été chassée de son âme, mais peut revenir s'il l'y invite de nouveau. « Tout comme la nuit suit le jour, les ténèbres poursuivent nos cœurs, prévient-elle. Vous devez rester ferme, vigilant et brave, car les ténèbres ne se chassent pas aussi facilement une deuxième fois. Comprenez-vous ? »

Quelle que soit sa réponse, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-saint-markovia">Markovia</a> souhaite bonne chance aux joueurs et prend congé avant de disparaître de la surface du bassin.
<a id="en-q4-the-revenants-warning" data-traduction="ancre"></a>
# Q4. L'avertissement du revenant
Peu après la victoire des joueurs sur <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>, le **<a href="https://www.aidedd.org/dnd/monstres.php?vf=revenant">revenant</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-revenant-monstre"><sup>fiche</sup></a>** de la croisée de la rivière du Corbeau se rend à Krezk et demande à les rencontrer. Un **<a href="https://www.aidedd.org/dnd/monstres.php?vf=garde">garde</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-guard-monstre"><sup>fiche</sup></a>** nommé <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-harkus-grejenko">Harkus Grejenko</a> est chargé de les trouver et de les appeler auprès de lui.

Si les joueurs s'y rendent, le <a href="https://www.aidedd.org/dnd/monstres.php?vf=revenant">revenant</a> leur annonce gravement qu'il a reçu un message d'un **<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-campagne-phantom-warrior">guerrier fantomatique</a>** d'Argynvostholt et leur communique les informations suivantes :

* Le <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">commandant Vladimir Horngaard</a> a ordonné à tous les <a href="https://www.aidedd.org/dnd/monstres.php?vf=chevalier">chevaliers</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-knight-monstre"><sup>fiche</sup></a> de l'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-order-of-the-silver-dragon">ordre du Dragon d'argent</a> de rentrer à Argynvostholt au plus tard demain à midi.
* Le commandant Horngaard est furieux de la récente incursion des joueurs au château Ravenloft et veut leur mort, afin qu'ils cessent de s'en prendre à <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-strahd-von-zarovich">Strahd von Zarovich</a>.
* Le commandant Horngaard devrait donner un nouvel ordre à ses <a href="https://www.aidedd.org/dnd/monstres.php?vf=chevalier">chevaliers</a> : détruire les joueurs à tout prix.

Le <a href="https://www.aidedd.org/dnd/monstres.php?vf=revenant">revenant</a> s'excuse sincèrement « du mal qu'il pourrait être contraint de leur infliger s'ils se rencontrent de nouveau ». Si les joueurs disent ou laissent entendre qu'ils sont allés à Argynvostholt, il leur demande s'ils ont parlé à <a href="../Appendices/Non-Player%20Characters.md#en-sir-godfrey-gwilym">messire Godfrey Gwilym</a> et entendu parler de la mission qu'il cherchait à accomplir. S'ils ont récupéré le crâne d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> conformément aux souhaits du dragon, il les presse d'accomplir sa prophétie avant que le commandant Horngaard « déchaîne toute sa fureur sur eux ».

Contraint d'obéir aux ordres de <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a>, le <a href="https://www.aidedd.org/dnd/monstres.php?vf=revenant">revenant</a> ne peut être persuadé de rester à Krezk. Il repart dès qu'il a transmis son message.

# Q5. L'attaque de la meute

> [!abstract]+ **La meute attaque-t-elle ?**
> Cette scène n'a lieu que si (1) les joueurs ont emporté le *Symbole sacré* de l'antre des <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup-garou">loups-garous</a> <a href="../Appendices/Bestiary.md#en-werewolf"><sup>fiche</sup></a>, révélant ainsi un vol au sanctuaire de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-mother-night">Mère Nuit</a>, ou (2) ils n'ont pas masqué leur odeur, par exemple avec *<a href="https://www.aidedd.org/dnd/sorts.php?vf=passage-sans-trace">passage sans trace</a>*, en s'infiltrant dans l'antre dans [Arc L : L'antre des loups](Arc%20L%20-%20The%20Den%20of%20Wolves.md), ce qui a permis à <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> de détecter l'intrusion d'étrangers.
<a id="en-q5a-the-pack-arrives" data-traduction="ancre"></a>
## Q5a. L'arrivée de la meute
À la tombée de la nuit du jour où les joueurs affrontent <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">l'Abbé</a>, s'ils ne l'ont pas encore vaincu, <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril Stoyanovich</a> rassemble la meute, qui comprend dix-huit **<a href="https://www.aidedd.org/dnd/monstres.php?vf=loup">loups</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-wolf-monstre"><sup>fiche</sup></a>** et huit **<a href="https://www.aidedd.org/dnd/monstres.php?vf=loup-garou">loups-garous</a> <a href="../Appendices/Bestiary.md#en-werewolf"><sup>fiche</sup></a>**, et la conduit aux ruines de Berez. Il y consulte <a href="../Appendices/Non-Player%20Characters.md#en-baba-lysaga">Baba Lysaga</a>, qui utilise sa magie pour déterminer où se trouvent les joueurs. <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> y mène alors sa meute, dans l'intention de tuer et de dévorer les intrus qui se sont introduits dans l'antre.

***Hors des remparts.*** Si les joueurs ont installé leur camp à la tour de <a href="../Appendices/Non-Player%20Characters.md#en-dr-rudolph-van-richten">Van Richten</a> ou à Argynvostholt, un chœur de hurlements, dominé par un rugissement grave et terrible, les réveille.

Lorsque les joueurs s'approchent de la meute pour la première fois, lisez :

<div class="description">
<p>Plus de deux douzaines de <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup">loups</a> émergent de l'épais brouillard qui s'accroche au sol dehors, leurs yeux dorés luisant dans la faible lumière lunaire. Une silhouette monstrueuse à deux pattes se tient à leur tête, son crâne hirsute presque à la hauteur d'un étage entier.</p>
</div>

Si <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil Toranescu</a> accompagne les joueurs, son poing se serre le long de son corps et ses ongles s'allongent en griffes. « <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> », murmure-t-il.

***À l'intérieur des remparts.*** Si les joueurs se reposent à Krezk ou à Vallaki, <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> arrive devant les portes avec sa meute et exige des <a href="https://www.aidedd.org/dnd/monstres.php?vf=garde">gardes</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-guard-monstre"><sup>fiche</sup></a> qu'ils lui amènent « les étrangers, la vermine qui a piétiné son antre ». Un <a href="https://www.aidedd.org/dnd/monstres.php?vf=garde">garde</a> terrifié porte le message à la chaumière des Krezkov, à Krezk, ou à l'auberge de l'Eau bleue, à Vallaki, dans l'espoir d'y trouver les joueurs. (S'ils n'y sont pas, le baron Krezkov ou <a href="../Appendices/Non-Player%20Characters.md#en-urwin-martikov">Urwin Martikov</a> leur transmet le message en personne.)

Lorsque les joueurs s'approchent de la meute pour la première fois, lisez :

<div class="description">
<p>Plus de deux douzaines de <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup">loups</a> émergent de l'épais brouillard qui s'accroche au sol dehors, leurs yeux dorés luisant dans la faible lumière lunaire.</p>
</div>

Les <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup">loups</a> montrent les crocs, mais n'attaquent pas immédiatement. Un joueur dont la Sagesse (Perception) passive est de 12 ou plus remarque qu'ils paraissent étonnamment mal nourris : on voit les côtes de certains sous leur peau. Si <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil Toranescu</a> les accompagne, un joueur dont la Sagesse (Perspicacité) passive atteint 13 constate que les <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup">loups</a> semblent le regarder avec surprise et appréhension. Si <a href="../Appendices/Non-Player%20Characters.md#en-bianca-stoyanovich">Bianca Stoyanovich</a> est encore en vie, elle se tient raide sur le côté de la meute, pâle et silencieuse.

> [!info]+ **Les <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup">loups</a> affamés**
> Par gourmandise et par orgueil, <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> s'est réservé la première part, et de loin la plus grosse, de chaque proie chassée par la meute depuis la disparition d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a>. Les autres membres de la meute, à l'exception de <a href="../Appendices/Non-Player%20Characters.md#en-bianca-stoyanovich">Bianca</a>, souffrent donc de malnutrition et de privations depuis plusieurs semaines. Réduits à survivre de lapins, de rats et d'autres petits gibiers, ils ont beaucoup maigri.

Peu après que les joueurs ont approché les <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup">loups</a>, ou dès qu'ils appellent <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a>, lisez :

<div class="description">
<p>Une silhouette monstrueuse à deux pattes sort pesamment de la brume, son crâne hirsute presque à la hauteur d'un étage entier.</p>
</div>

Si <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil Toranescu</a> accompagne les joueurs, son poing se serre le long de son corps et ses ongles s'allongent en griffes. « <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> », murmure-t-il.
<a id="en-q5b-kirils-challenge" data-traduction="ancre"></a>
## Q5b. Le défi de Kiril

> [!abstract]+ **Des joueurs impatients**
> <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> ne se sent pas menacé par les joueurs. Ainsi, la première fois qu'un joueur l'attaque avec une arme non argentée, un sort de niveau inférieur à 3 ou une attaque ou un sort qui n'inflige pas de dégâts nécrotiques, il rit en voyant sa régénération naturelle refermer ses blessures, au lieu de riposter. « Tu me chatouilles en t'agitant, petite bouchée », gronde-t-il. Il se pourlèche les babines en fixant le joueur avec gourmandise. « Je te laisserai peut-être me chatouiller les dents ensuite. J'ai un ou deux morceaux de viande coincés là-dedans, et un peu d'aide pour les retirer serait bienvenue. »
>
> La deuxième fois qu'un joueur attaque, ou si un joueur utilise une arme argentée, une attaque ou un sort infligeant des dégâts nécrotiques, ou un sort de niveau 3 ou plus, <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> gronde, les narines dilatées et les yeux brusquement écarquillés. « Pressé de mourir, petite bouchée ? Je ne vais pas te faire attendre. » Il passe alors à l'attaque.

> [!info]+ **Rayon de lune**
> La corruption de <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> a fait de sa forme hybride, plutôt que de sa forme humaine, sa « véritable forme ». Il subit normalement les dégâts de *<a href="https://www.aidedd.org/dnd/sorts.php?vf=rayon-de-lune">rayon de lune</a>*, mais ce sort ne peut pas lui faire reprendre forme humaine.

Lorsque les joueurs s'approchent de <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> pour la première fois, ou l'inverse, lisez :

<div class="description">
<p>La silhouette monstrueuse avance, un rayon de lune argenté éclairant la fourrure noire comme le charbon qui recouvre sa peau.</p>
<p>Elle dépasse de peu les neuf pieds de haut ; ses bras, ses jambes et son torse sont couverts d'épais muscles noueux. Ses crocs en forme de cimeterres dépassent de son museau et descendent si bas sous sa mâchoire qu'ils ressemblent presque à des défenses. Ses griffes longues et sombres, tachées de couches de sang, se crispent et se détendent avec avidité, comme prêtes à trancher de nouveau la chair.</p>
<p>Les iris écarlates de la bête percent la brume qui tourbillonne autour d'elle et à ses pieds, et son museau lupin se retrousse en un rictus bestial. Sa voix est un grondement grave et hargneux qui résonne dans la nuit lugubre.</p>
<p>« Alors, c'est vous, les petites souris qui ont couru dans mon antre », gronde la bête. Elle se lèche les babines avec une gourmandise manifeste ; un filet de salive coule de ses dents irrégulières. « Vous ne pouviez pas fuir éternellement, on dirait. »</p>
</div>

> [!info]+ **Les clés de <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a>**
> Les joueurs qui examinent le cou de <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> remarquent deux clés suspendues à une chaîne. Celle-ci se brise lorsque <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> entre dans sa deuxième phase (voir ci-dessous), ce qui leur permet de les récupérer. Ces clés ouvrent les *<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-campagne-silverthorn-collar">colliers d'épine d'argent</a>* qui retiennent <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-ilya-krezkov">Ilya</a> et <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zuleika-toranescu">Zuleika</a> prisonniers dans l'antre des <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup-garou">loups-garous</a> <a href="../Appendices/Bestiary.md#en-werewolf"><sup>fiche</sup></a>.

Cette bête est <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> dans sa première phase (voir ci-dessous). Si <a href="../Appendices/Non-Player%20Characters.md#en-ezmerelda-davenir">Ezmerelda</a> est présente, ses yeux s'écarquillent et elle souffle aux joueurs qu'elle reconnaît les motifs de sa fourrure. « Ce salaud est plus gros qu'il y a deux ans, murmure-t-elle entre ses dents serrées, mais c'est bien <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">la Terreur noire</a>. » (Si on le lui demande, elle peut rappeler discrètement aux joueurs que <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">la Terreur noire</a> est le surnom du <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup-garou">loup-garou</a> qui lui a arraché la jambe.)

Comme un chat qui joue avec sa proie, <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> ne se presse pas de tuer les joueurs ; il espère les provoquer, les rabaisser et les démoraliser avant d'attaquer. Pendant la conversation, si <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil Toranescu</a> est présent, lisez :

<div class="description">
<p>Le regard de <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> glisse vers l'homme à vos côtés et sa babine noire se retrousse. Il le fixe un instant, puis rejette la tête en arrière dans un rire tonitruant.</p>
<p>« Vous avez ramené l'avorton ! tonne-t-il. Félicitations, mauviette. Qu'est-ce que ça fait de savoir qu'il t'a fallu ces <em>souris</em> pour te sauver ? Je suis impressionné, quand même. Comment <em>ont-elles</em> fait ? »</p>

> [!abstract]+ **<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a> emprisonné**
> Si les joueurs n'ont pas sauvé <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a> du château Ravenloft, <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> ordonne aux <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup">loups</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-wolf-monstre"><sup>fiche</sup></a> qui l'entourent de les tuer lorsqu'il estime la conversation terminée. Les joueurs qui soulignent la faim manifeste des <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup">loups</a> et réussissent un test de Charisme (Persuasion) DD 18 peuvent convaincre la meute de rester en retrait pendant qu'ils affrontent <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> directement. Sinon, les <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup">loups</a> et les <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup-garou">loups-garous</a>, sauf <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a>, attaquent. <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> les attaque dès que le reste de la meute est vaincu ou tué.

À un moment approprié de la conversation, si <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a> est présent, il défie <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> pour la direction de la meute. À moins que les joueurs les interrompent, l'échange suivant a lieu :

* <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a> s'avance, les yeux luisant d'or dans la lumière faible. « <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a>, déclare-t-il, je ne peux rester sans rien faire devant ce que tu as fait à notre meute, à notre famille. Tu l'as trahie pour satisfaire ton orgueil, ta faim et ton ego. »
* <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> retrousse son museau en un sourire lupin dévoilant ses dents. « L'orgueil ? La faim ? C'est de la *force*, mauviette. Je n'ai apporté que de la gloire à la meute. »
* <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a> plisse les yeux. « C'est *toi* que tu as cherché à couvrir de gloire. »
* <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> gronde. « Je suis l'alpha ! Ma gloire exalte la meute. »
* « Un chef *prend soin* de sa meute, répond froidement <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a>. Il chasse pour elle, pas pour lui-même. »
* « Alors, tu me défies, avorton ? rétorque <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a>. Toi et tes petites souris ? »
* <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a> regarde les joueurs pour s'assurer de leur accord. S'ils souhaitent combattre <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> à ses côtés et ne répondent pas eux-mêmes, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a> se tourne vers <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> et déclare : « Oui. »
* <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> rit et répond : « Un loup ne se soucie pas de l'insolence des moutons. » Il regarde les <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup">loups</a> qui l'entourent, puis désigne les joueurs. « Tuez-les. »
* Alors que les autres membres de la meute avancent avec hésitation, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a> croise le regard du plus grand <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup">loup</a> et dit : « <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-kellen">Kellen</a>, c'est *ton* choix, pas le sien. » Le <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup">loup</a> hésite. <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a> se tourne vers le reste de la meute et ajoute : « Je vous ai déjà failli. Je n'ai aucun droit de vous demander votre loyauté. Je vous demande seulement de rester fidèles à vous-mêmes et les uns aux autres, pas à un homme qui exigerait votre soumission. » Il fait face à <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> sans ciller, sa main griffue se refermant en poing. « Car nous sommes des loups, pas des chiens. L'obéissance est l'affaire des hommes. »
* Un par un, les <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup">loups</a> s'arrêtent, se retournent et regagnent leur place, où ils s'assoient et attendent.
* Les yeux de <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> brillent d'écarlate, ses griffes et ses crocs s'allongent légèrement et son corps massif tremble de rage. « Lâches et traîtres ! » gronde-t-il. Il se tourne vers <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a> et les joueurs. « Quel dommage que le <a href="https://www.aidedd.org/dnd/monstres.php?vf=vampire">vampire</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-vampire-monstre"><sup>fiche</sup></a> ne puisse jamais récupérer son prisonnier, rugit-il. Quand j'en aurai fini avec vous, il ne restera pas un seul os ! »

<a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> attaque alors.

<a id="en-actions-3" data-traduction="ancre"></a>
<h3>Actions</h3>
<p><strong><em>Attaques multiples.</em></strong> <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> effectue trois attaques au corps à corps, dont une au maximum peut être une Morsure. Il peut ensuite utiliser immédiatement son <strong><em>hurlement de l'alpha</em></strong></p>
<p><strong><em>Griffe.</em></strong> <em>Attaque au corps à corps avec une arme</em>, +10 au toucher, allonge 5 pieds, 1 cible. <em>Touché :</em> 13 (2d8 + 4) dégâts tranchants, et la cible doit réussir un jet de sauvegarde de Force DD 17 sous peine d'être jetée à terre.</p>
<p><strong><em>Morsure.</em></strong> <em>Attaque au corps à corps avec une arme</em>, +10 au toucher, allonge 5 pieds, 1 cible. <em>Touché :</em> 11 (2d6 + 4) dégâts perforants. Si la cible est un humanoïde, elle doit réussir un jet de sauvegarde de Constitution DD 17 sous peine d'être maudite par la lycanthropie des <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup-garou">loups-garous</a> <a href="../Appendices/Bestiary.md#en-werewolf"><sup>fiche</sup></a> jusqu'à la mort de <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a>. Si elle était déjà atteinte de cette malédiction et avait acquis la régénération des <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup-garou">loups-garous</a>, elle ne peut plus se régénérer avant d'avoir terminé un repos long.</p>
<p><strong><em>Hurlement de l'alpha.</em></strong> Un nombre quelconque de cibles situées à 60 pieds ou moins, qui peuvent entendre <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> et que lui ou ses victimes infectées ont maudites par la lycanthropie des <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup-garou">loups-garous</a>, doivent effectuer un jet de sauvegarde de Sagesse DD 18. En cas de réussite, une cible perd un niveau de soif de sang (minimum 0). En cas d'échec, elle gagne un niveau de soif de sang (maximum 2) et doit immédiatement utiliser sa réaction, si elle en dispose, pour se déplacer d'une distance maximale égale à sa vitesse vers une créature aléatoire autre que <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a>. Si elle possède au moins un niveau de soif de sang, elle doit effectuer une attaque de griffes contre cette créature (voir ci-dessous). Si elle possède deux niveaux de soif de sang, elle doit aussi effectuer une attaque de morsure contre cette créature (voir ci-dessous).</p>
<p>Une cible ayant un niveau de soif de sang acquiert des griffes de loup. Elle peut les utiliser pour effectuer une attaque avec son modificateur de Force (minimum 2), qui inflige, si elle touche, 2d4 dégâts tranchants plus son modificateur de Force (minimum 2). Une cible ayant deux niveaux de soif de sang acquiert aussi un museau de loup. Elle peut utiliser sa morsure pour effectuer une attaque avec son modificateur de Force (minimum 2), qui inflige, si elle touche, 1d8 dégâts perforants plus son modificateur de Force (minimum 2). Une cible en proie à la soif de sang maîtrise ses griffes et sa morsure. Un humanoïde ainsi mordu doit réussir un jet de sauvegarde de Constitution DD 18 sous peine d'être maudit par la lycanthropie des <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup-garou">loups-garous</a> jusqu'à la mort de <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a>.</p>
<a id="en-bonus-actions-3" data-traduction="ancre"></a>
<h3>Actions bonus</h3>
<p><strong><em>Frénésie sauvage.</em></strong> <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> bondit d'une distance maximale égale à sa vitesse sans provoquer d'attaques d'opportunité. Chaque créature située à 5 pieds ou moins de lui doit ensuite effectuer un jet de sauvegarde de Dextérité DD 18 ; elle subit 14 (4d6) dégâts tranchants en cas d'échec, ou la moitié de ces dégâts en cas de réussite.</p>
<p><strong><em>Métamorphose.</em></strong> <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> se transforme en humain ou en <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup-sanguinaire">loup sanguinaire</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-dire-wolf-monstre"><sup>fiche</sup></a>, ou reprend sa véritable forme, celle d’un hybride loup-humanoïde. Ses caractéristiques, à l’exception de sa CA, sont identiques sous chaque forme. L’équipement porté ou tenu ne se transforme pas. Il reprend sa forme humaine s’il meurt.</p>
<a id="en-reactions-3" data-traduction="ancre"></a>
<h3>Réactions</h3>
<p><a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> peut effectuer jusqu’à trois réactions par round, mais une seule par tour. Si un effet ou un état devait empêcher ses réactions, une seule réaction est perdue à la place.</p>
<p><strong><em>Indomptable.</em></strong> <strong>Déclencheur :</strong> Une créature hostile termine son tour. <strong>Effet :</strong> <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> peut réitérer le jet de sauvegarde contre un effet ou un état qui l’affecte actuellement. (Cette réaction est sans effet si l’effet ou l’état ne nécessitait pas, à l’origine, de rater un jet de sauvegarde.)</p>
<p><strong><em>Bond prédateur.</em></strong> Lorsqu’une créature se déplace à 30 pieds ou moins, <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> se déplace vers elle d’une distance maximale égale à sa vitesse sans provoquer d’attaques d’opportunité.</p>
<p><strong><em>Riposte sauvage.</em></strong> Lorsqu'une créature qu'il peut voir, entendre ou sentir le rate avec une attaque, <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> se déplace vers elle d'une distance maximale égale à sa vitesse sans provoquer d'attaques d'opportunité. Il peut ensuite l'attaquer avec ses griffes si elle est à portée de son allonge.</p>
<p><strong><em>Déchiquetage.</em></strong> Lorsqu'une créature située à 5 pieds ou moins le touche avec une attaque, <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> l'attaque avec sa morsure.</p>

<h3>Actions</h3>
<p><strong><em>Attaques multiples.</em></strong> <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> effectue une attaque de griffes et une attaque de morsure. Il peut remplacer la morsure par un engloutissement s’il entrave déjà une cible avec sa morsure.</p>
<p><strong><em>Griffes.</em></strong> <em>Attaque au corps à corps avec une arme :</em> +11 au toucher, allonge 10 pieds, 1 cible. <em>Touché :</em> 15 (4d4 + 5) dégâts tranchants, et la cible doit réussir un jet de sauvegarde de Dextérité DD 18 sous peine d'être repoussée de 10 pieds ou agrippée, au choix de <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a>.</p>
<p><strong><em>Morsure.</em></strong> <em>Attaque au corps à corps avec une arme :</em> +11 au toucher, allonge 10 pieds, 1 cible. Touché : 27 (4d10 + 5) dégâts perforants. Si la cible est de taille G ou inférieure, elle est agrippée (évasion DD 18). Tant que cette lutte se poursuit, la cible est entravée et <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> ne peut pas mordre d'autre cible.</p>
<p><strong><em>Engloutissement.</em></strong> <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> effectue une attaque de morsure contre une créature de taille M ou inférieure qu’il a entravée avec sa morsure. Si l’attaque touche, la cible subit les dégâts de la morsure, elle est engloutie et l’agrippade prend fin. Une créature engloutie est aveuglée et entravée, bénéficie d’un abri total contre les attaques et les autres effets provenant de l’extérieur de <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a>, et subit 7 (2d6) dégâts d’acide au début de chacun des tours de <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a>. Si <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> subit 20 dégâts ou plus au cours d’un même tour, il doit réussir un jet de sauvegarde de Constitution DD 20 à la fin de ce tour sous peine de régurgiter toutes les créatures englouties, qui tombent à terre dans un espace situé à 10 pieds ou moins de lui. <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> doit également régurgiter immédiatement toutes les créatures englouties s’il meurt.</p>

<h3>Actions bonus</h3>
<p><strong><em>Miasme corrompu.</em></strong> <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> exhale un nuage de brume nécrotique. Chaque créature située à 20 pieds ou moins de lui doit réussir un jet de sauvegarde de Sagesse DD 18. Elle subit 9 (2d8) dégâts nécrotiques en cas d’échec, ou la moitié de ces dégâts en cas de réussite.</p>
<p><strong><em>Rayon d’ombre.</em></strong> Un rayon d’ombres tourbillonnantes de 5 pieds de large et de 100 pieds de long jaillit de la gueule de <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a>. Chaque créature dans cette zone doit effectuer un jet de sauvegarde de Dextérité DD 18. Elle subit 14 (4d6) dégâts nécrotiques en cas d’échec, ou la moitié de ces dégâts en cas de réussite. Une cible agrippée par la morsure de <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> rate automatiquement ce jet de sauvegarde.</p>
<a id="en-reactions-4" data-traduction="ancre"></a>
<h3>Réactions</h3>
<p><a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> peut effectuer jusqu’à trois réactions par round, mais une seule par tour. Si un effet ou un état devait empêcher ses réactions, une seule réaction est perdue à la place.</p>
<p><strong><em>Indomptable.</em></strong> <strong>Déclencheur :</strong> Une créature hostile termine son tour. <strong>Effet :</strong> <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> peut réitérer le jet de sauvegarde contre un effet ou un état qui l’affecte actuellement. (Cette réaction est sans effet si l’effet ou l’état ne nécessitait pas, à l’origine, de rater un jet de sauvegarde.)</p>
<p><strong><em>Bond.</em></strong> Lorsqu'une créature se déplace à 30 pieds ou moins de lui, effectue une attaque à distance contre lui ou lance un sort, <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> bondit vers elle sans provoquer d'attaques d'opportunité. Chaque créature située dans un rayon de 5 pieds autour de lui doit alors immédiatement réussir un jet de sauvegarde de Force DD 19 sous peine de tomber à terre. <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> peut ensuite attaquer avec ses griffes la créature qui s'est déplacée, a attaqué ou a lancé un sort.</p>
<p><strong><em>Dévoration.</em></strong> La première fois pendant un tour qu’une créature entre dans son allonge, <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> l’attaque avec sa morsure s’il ne mord pas déjà une autre créature. Si l’attaque rate, cette créature bénéficie d’un avantage à sa prochaine attaque contre <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> avant le début de son prochain tour.</p>
<p><strong><em>Immobilisation.</em></strong> Lorsqu'une créature à portée de son allonge le rate avec une attaque, ou qu'une créature quitte son allonge, <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> l'attaque avec ses griffes. S'il l'agrippe, elle doit réussir un jet de sauvegarde de Force supplémentaire DD 19 sous peine de tomber à terre.</p>
</div>

> [!warning]+ **Sauter en agrippant une créature**

> Étant de taille TG, <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> peut atterrir sur des créatures de taille M ou inférieure et bondir tout en agrippant des créatures avec ses griffes ou sa morsure.

> [!warning] **Traîner des créatures agrippées**

## Q5c. Kiril vaincu

> [!info]+ **Le sort de <a href="../Appendices/Non-Player%20Characters.md#en-bianca-stoyanovich">Bianca</a>**
> Une fois <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> abattu, la réaction de <a href="../Appendices/Non-Player%20Characters.md#en-bianca-stoyanovich">Bianca</a> dépend de ses interactions passées avec le groupe. C'est une femme tiraillée entre l'amour, le chagrin et les traumatismes d'une vie dans l'ombre de <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a>.

> 
> **Si le groupe est resté distant ou neutre :**
> 
> <a href="../Appendices/Non-Player%20Characters.md#en-bianca-stoyanovich">Bianca</a> reste figée par le choc, les yeux écarquillés. Après un long moment, elle se retourne sans un mot et marche vers la lisière de la forêt. Si les personnages l'appellent ou la suivent, elle s'arrête sans se retourner. « Comment pourrais-je revenir après tout ce qu'il a fait ? demande-t-elle. Ils le verront chaque fois qu'ils me regarderont. » Elle se tait et fixe les arbres. « J'ai juste besoin d'être ailleurs pendant quelque temps. Quelque part où il n'a jamais été. » Si les joueurs ne s'y opposent pas, elle disparaît dans la forêt.
> 
> **Si le groupe l'a braquée, menacée ou rendue furieuse :**
> 
> Lorsque <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> tombe, le chagrin de <a href="../Appendices/Non-Player%20Characters.md#en-bianca-stoyanovich">Bianca</a> se change en fureur. Elle hurle et, dans une poussée de rage aveugle, se jette sur les joueurs, combattant sans retenue jusqu'à être tuée.

<p>« Puissiez-vous affronter la mort avec honneur et courage, grince l'un des <a href="https://www.aidedd.org/dnd/monstres.php?vf=revenant">revenants</a>, comme notre général l'a ordonné. »</p>

Un joueur peut tenter un test de Charisme (Persuasion) DD 15 pour convaincre les <a href="https://www.aidedd.org/dnd/monstres.php?vf=revenant">revenants</a> de résister à l'emprise des fils. Le test se fait avec avantage si les joueurs expliquent qu'ils ont récupéré le crâne d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> au château Ravenloft et comptent le replacer dans son mausolée. En cas de réussite, les <a href="https://www.aidedd.org/dnd/monstres.php?vf=revenant">revenants</a> effectuent leurs attaques et leurs jets de sauvegarde de Dextérité avec désavantage, et toutes les attaques contre eux bénéficient d'un avantage.

Lorsque les joueurs vainquent le dernier <a href="https://www.aidedd.org/dnd/monstres.php?vf=revenant">revenant</a>, celui-ci les avertit que le commandant Horngaard les attend au cimetière. « Puisse le <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-morninglord">Seigneur de l'Aube</a> vous protéger », grince-t-il avant de s'effondrer.

> [!abstract]+ **L'ordre de <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a>**

## Q6b. Retour au cimetière
Lorsque les joueurs reviennent pour la première fois au <span class="citation">Q15. Cimetière (p. 134)</span> après avoir récupéré le crâne d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> dans [Arc P : Le cambriolage de Ravenloft](Arc%20P%20-%20Ravenloft%20Heist.md), ils le trouvent apparemment désert. La porte de pierre du <span class="citation">Q16. Mausolée du dragon (p. 134)</span> est ouverte.

> [!abstract]+ **Des joueurs qui se téléportent**

La première fois que les joueurs entrent dans le cimetière, s'ils ne se déplacent pas discrètement ou ratent un test de groupe de Dextérité (Discrétion) DD 19, <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> les entend et sort du mausolée pour leur parler. Lisez :

Chaque créature dans une sphère de 10 pieds de rayon centrée sur ce point doit effectuer un jet de sauvegarde de Dextérité DD 17. La sphère contourne les angles. Une créature subit 10 (3d6) dégâts de feu plus 10 (3d6) dégâts nécrotiques en cas d’échec, ou la moitié de ces dégâts en cas de réussite. En cas d’échec, une créature subit également un désavantage à la prochaine attaque qu’elle effectue avant le début du prochain tour de <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a>.</p>
<p><strong><em>Vague destructrice.</em></strong> <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> frappe le sol avec son <a href="https://www.aidedd.org/regles/equipement/armes/">épée à deux mains</a> et crée une vague d’énergie destructrice qui se propage autour de lui. Chaque créature située à 10 pieds ou moins de lui doit réussir un jet de sauvegarde de Constitution DD 18 sous peine de subir 10 (3d6) dégâts de tonnerre plus 10 (3d6) dégâts nécrotiques et d’être jetée à terre. Une créature qui réussit le jet subit la moitié des dégâts et n’est pas jetée à terre.</p>
<a id="en-reactions-6" data-traduction="ancre"></a>
<h3>Réactions</h3>
<p><a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> peut effectuer jusqu’à trois réactions par round, mais une seule par tour. Si un effet ou un état devait empêcher ses réactions, une seule réaction est perdue à la place.</p>
<p><strong><em>Indomptable.</em></strong> <strong>Déclencheur :</strong> Une créature hostile termine son tour. <strong>Effet :</strong> <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> peut réitérer le jet de sauvegarde contre un effet ou un état qui l’affecte actuellement. (Cette réaction est sans effet si l’effet ou l’état ne nécessitait pas, à l’origine, de rater un jet de sauvegarde.)</p>
<p><strong><em>Ruée vengeresse.</em></strong> Lorsqu’un ennemi le touche ou le rate avec une attaque, <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> charge vers lui et se déplace d’un maximum de 15 pieds en ligne droite vers lui sans provoquer d’attaques d’opportunité. Si <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> termine son déplacement à 5 pieds ou moins de cet ennemi, il peut le contraindre à effectuer un jet de sauvegarde de Force DD 18. En cas d’échec, la cible subit 2d6 dégâts contondants, puis <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> et elle se déplacent d’un maximum de 10 pieds supplémentaires dans la même direction, sans provoquer d’attaques d’opportunité. Si la cible ne peut pas parcourir toute cette distance, elle subit 1d6 dégâts contondants supplémentaires par tranche de 5 pieds qu’elle n’a pas pu parcourir.</p>
<p><strong><em>Regard vengeur.</em></strong> Lorsqu’un ennemi situé à 30 pieds ou moins lui inflige des dégâts, <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> le contraint à effectuer un jet de sauvegarde de Sagesse DD 17. En cas d’échec, la créature est effrayée par <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> jusqu’à ce qu’il lui inflige des dégâts ou jusqu’à la fin du prochain tour de <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a>. Si la créature rate le jet de 5 ou plus, elle est paralysée à la place.</p>
<p><strong><em>Frappe de la sentinelle.</em></strong> Lorsqu’une créature tente de quitter son allonge sans avoir d’abord effectué l’action Se désengager, <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> l’attaque avec son <strong><em>épée à deux mains +2</em></strong>. Si l’attaque touche, la créature ne subit aucun dégât, mais tombe à terre et sa vitesse devient 0 pour le reste du tour.</p>
</div>

<a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> attaque si les joueurs l'attaquent d'abord ou s'il juge inutile de poursuivre la conversation. S'ils demandent à remettre le crâne d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> dans le mausolée, il hésite brièvement, puis secoue la tête. « Vous êtes trop dangereux pour qu'on vous laisse vivre, gronde-t-il. Votre hostilité envers von Zarovich représente une menace que je ne tolérerai pas. Quand vous serez en terre, j'accomplirai peut-être la tâche que vous vous êtes fixée, mais pas avant que votre dernier souffle ait quitté vos corps. »

Lorsque <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> entre dans sa deuxième phase, quatre **<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-campagne-phantom-warrior">guerriers fantomatiques</a>** se matérialisent pour l'aider. Ils combattent jusqu'à la mort.

De plus, la première fois qu'un joueur entre dans le mausolée, <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> utilise une de ses réactions pour invoquer un cercle de feu noir autour du cimetière. Lisez :

<div class="description">
<p>Des ombres d'un noir de jais tourbillonnent depuis les torches de part et d'autre de la porte béante du mausolée. Des flammes sombres jaillissent du sol de pierre de la crypte et se propagent avec avidité dans l'herbe mourante du cimetière, formant un cercle de feu noir le long des murs du manoir et de la clôture en fer forgé.</p>
</div>

Une onde de force jaillit du point d'origine des flammes. Chaque joueur situé à 5 pieds ou moins de l'entrée du mausolée doit réussir un jet de sauvegarde de Force DD 18 ; en cas d'échec, il est projeté à 10 pieds du mausolée et tombe à terre.

Les flammes bloquent la sortie en haut des marches de la chapelle, formant une nappe de feu noir de huit pieds de haut autour du cimetière. Une créature subit 10 (3d6) dégâts de feu plus 10 (3d6) dégâts nécrotiques lorsqu'elle entre dans les flammes pour la première fois d'un tour ou y termine son tour. Un joueur peut sauter par-dessus les flammes s'il est capable d'un saut en hauteur de huit pieds (voir <span class="citation">Saut en hauteur, <em>Manuel des joueurs</em> (p. 182)</span>) ou s'il réussit un test de Force (Athlétisme) DD 18. (S'il porte seul tout le poids du crâne d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a>, sa hauteur de saut est réduite de 3 pieds et il effectue ce test de Force (Athlétisme) avec désavantage.) En cas d'échec, il tombe à terre dans les flammes.
<a id="en-q6c-argynvosts-return" data-traduction="ancre"></a>
## Q6c. Le retour d'Argynvost
La première fois qu'un joueur dépose le crâne d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> dans une alcôve du mausolée, lisez :

<div class="description">
<p>Une lumière argentée palpite dans la brume qui rampe sur le sol, tandis que des volutes de brouillard nacré s'élèvent vers le crâne massif. La pierre de la crypte tremble et la température chute brutalement ; deux points de lumière argentée s'allument dans les grandes orbites du crâne.</p>
<p>Dans un rugissement aussi puissant que le tonnerre, une nuée de brume argentée surgit des profondeurs du mausolée et se répand dans le cimetière. L'épais brouillard bouillonne de reflets argentés tandis qu'une forme immense se dessine lentement dans les airs.</p>
<p>Des griffes émergent d'abord, puis un torse sinueux long de la moitié de la hauteur du manoir, qui se prolonge en un cou élégant couronné d'une noble tête cornue. De puissantes ailes s'étendent depuis de robustes épaules, leurs écailles spectrales scintillant d'une lumière argentée et éthérée tandis qu'elles emplissent le ciel.</p>
</div>

![[Argynvost_transparent.webp]]

<span class="credit">« Le fantôme d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> » par Caleb Cleveland. Soutenez-le sur <a href="https://patreon.com/calebisdrawing/">Patreon !</a></span>

À l'apparition de l'esprit d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a>, les <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-campagne-phantom-warrior">guerriers fantomatiques</a> tombent à genoux et baissent la tête devant lui. S'il est encore en vie, <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> cesse son assaut, laisse tomber son <a href="https://www.aidedd.org/regles/equipement/armes/">épée à deux mains</a> et regarde le dragon avec incrédulité. Lisez :

<div class="description">
<p>Le dragon spectral incline son grand cou, ses yeux luisant de tristesse. « Mes <a href="https://www.aidedd.org/dnd/monstres.php?vf=chevalier">chevaliers</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-knight-monstre"><sup>fiche</sup></a>, gronde-t-il. Qu'est-ce que cette contrée vous a fait ? »</p>
<p>Le gantelet rouillé de <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> se referme en poing. « Nous avons combattu, affirme-t-il d'une voix rauque, tremblante d'épuisement et de douleur. Nous avons tenu bon. »</p>
<p>« Avez-vous sombré si profondément dans l'ombre que vous ne voyez plus ce que vous êtes devenus ? » répond le dragon. Un grondement profond et douloureux monte de son vaste poitrail. « Vous avez abandonné le courage pour la peur, et la foi pour le désespoir. Ainsi, vous m'avez oublié. »</p>
<p>« Jamais », jure <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a>. Des larmes tombent de ses yeux et tachent la terre humide. « Nous n'aurions jamais… <em>Je</em> n'aurais jamais renoncé à la foi. »</p>
<p>Le dragon l'observe un instant. « Non, gronde-t-il enfin. Ta foi est forte, en vérité, pour t'avoir soutenu si longtemps. » Sa grande main griffue descend du ciel, ses serres tendues vers <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> dans une invitation évidente.</p>
<p>« Mais le temps du combat est passé, dit le dragon. Tu as tenu bon assez longtemps, mon brave <a href="https://www.aidedd.org/dnd/monstres.php?vf=chevalier">chevalier</a>. Le temps est venu de te reposer. »</p>
<p><a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> contemple la main devant lui, le corps tremblant. Lentement, il lève un gantelet vers elle, puis s'arrête. « Que me reste-t-il, lâche-t-il entre ses dents, sinon la souffrance de celui qui m'a pris tout ce que j'aimais ? »</p>
<p>Le dragon pose sur lui un regard sombre, puis se tourne lentement vers vous, comme pour vous inviter à parler.</p>
</div>

Les joueurs peuvent donner à <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> toute bonne raison d'accepter le repos offert par <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a>, y compris la promesse de ramener la paix dans la vallée en détruisant <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-strahd-von-zarovich">Strahd</a>. Lorsqu'ils ont terminé et que <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> leur a répondu, si nécessaire, lisez :

<div class="description">
<p>La mâchoire de <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> tremble, puis s'immobilise. Il contemple encore un instant la main du dragon. Enfin, il murmure : « De ce jour jusqu'à la fin des temps. »</p>
<p>Il place sa main dans la paume du dragon.</p>
<p>« De ce jour jusqu'à la fin des temps », gronde le dragon. Son autre main descend et une immense griffe effleure tendrement la joue du <a href="https://www.aidedd.org/dnd/monstres.php?vf=chevalier">chevalier</a>. « Ta garde est terminée. »</p>
<p><a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> ferme les yeux et expire un souffle chargé de désir, de chagrin et, enfin, de soulagement. Le bout de ses doigts commence à s'effriter comme une fine cendre, puis ses paumes et ses avant-bras. Sa peau usée se détache en flocons qui tourbillonnent dans l'air frais et calme. La dissolution gagne son torse, puis ses jambes et, enfin, son vieux visage las.</p>
<p>Ses vêtements et son armure rouillée, désormais vides, tombent paisiblement sur la terre à côté de son épée.</p>
</div>

> [!info]+ **L'<a href="https://www.aidedd.org/regles/equipement/armes/">épée à deux mains</a> de <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a>**
> Les joueurs qui examinent ensuite les restes de <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> peuvent récupérer son <a href="https://www.aidedd.org/regles/equipement/armes/">épée à deux mains</a> et son symbole sacré, décrits dans la <span class="citation">Q36. Salle d'audience du dragon (p. 138)</span>.

À la mort de <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a>, tous les **<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-campagne-phantom-warrior">guerriers fantomatiques</a>** qui hantent encore Argynvostholt ou son cimetière se dissolvent en brume. Tout personnage maudit par l'aptitude ***lien du serment*** de <a href="../Appendices/Non-Player%20Characters.md#en-commander-vladimir-horngaard">Vladimir</a> est délivré de ses contraintes. Les esprits des **<a href="https://www.aidedd.org/dnd/monstres.php?vf=revenant">revenants</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-revenant-monstre"><sup>fiche</sup></a>** de l'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-order-of-the-silver-dragon">ordre du Dragon d'argent</a>, y compris <a href="../Appendices/Non-Player%20Characters.md#en-sir-godfrey-gwilym">messire Godfrey Gwilym</a>, sont libérés des cadavres qu'ils habitent. Lisez :

<div class="description">
<p>Depuis la chapelle vous parvient un cliquetis de chaînes, accompagné du frôlement d'un vent murmurant. Lentement, une nouvelle silhouette spectrale prend forme dans le brouillard, sous l'ombre du dragon : cette fois humanoïde, grande et vêtue d'une armure étincelante.</p>
<p>Sa chevelure autrefois blanche brille désormais d'un or éthéré et tombe en épaisses ondulations sur ses épaules. Ses yeux écarlates et hantés sont devenus d'un bleu perçant. Son visage n'est plus décharné ni squelettique : il est noble et plein, aux pommettes saillantes, à la mâchoire carrée et aux yeux bordés de rides chaleureuses. Sa peau autrefois livide et cadavérique rayonne de la chaleur de la vie passée, et le col orné qui pesait si lourd sur ses épaules se dresse fièrement sous son cou.</p>
<p>En vous voyant, l'esprit porte solennellement un poing à sa poitrine et pose un genou à terre, inclinant la tête avec un profond respect. « Salut, mes amis », dit-il de sa voix grave mais douce, tremblante de gratitude et d'émerveillement. Il se frappe la poitrine du poing, des larmes de fierté et de joie coulant sur son visage spectral. « Salut, seigneur <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a>. »</p>
</div>

Les joueurs reconnaissent l'esprit de messire <a href="../Appendices/Non-Player%20Characters.md#en-sir-godfrey-gwilym">Godfrey</a>, qui a retrouvé l'apparence qu'il avait de son vivant.

L'esprit d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> salue messire <a href="../Appendices/Non-Player%20Characters.md#en-sir-godfrey-gwilym">Godfrey</a> avec chaleur et une profonde affection, puis les joueurs avec une immense gratitude. « Mes <a href="https://www.aidedd.org/dnd/monstres.php?vf=chevalier">chevaliers</a> avaient sombré dans les ténèbres. Vous les avez sauvés et leur avez montré la lumière qu'ils avaient perdue, tonne-t-il en inclinant bien bas la tête devant eux. Pour cela, je vous suis à jamais redevable. »

L'esprit d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> peut communiquer les informations suivantes si on l'interroge ou si les circonstances s'y prêtent :

* Il attend depuis longtemps quelqu'un qui remettrait sa dépouille à sa juste place, afin que son esprit ait la force de parler de nouveau à ses <a href="https://www.aidedd.org/dnd/monstres.php?vf=chevalier">chevaliers</a>. « Je suis reconnaissant que ma patience n'ait pas été vaine, gronde-t-il. Même mon espoir n'était plus qu'une lueur vacillante, mais vous en avez fait une flamme rugissante. »
* Son esprit est resté endormi pendant des siècles, jusqu'à ce qu'un lointain chant draconique l'éveille il y a quelques semaines : une harmonie venue des plans au-delà, que la Barovie n'avait plus entendue depuis la descente des Brumes. « Un grand alignement approche, murmure-t-il. J'ignore ce qu'il présage, mais les grands voiles bougent. »

<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> peut aussi raconter, sur demande, tous les événements de [l'ère de la Fondation](../Chapter%202%20-%20The%20Land%20of%20Barovia/History%20of%20Barovia.md#en-the-founding-era-1-bc345-bc) ou de [la naissance de la Barovie](../Chapter%202%20-%20The%20Land%20of%20Barovia/History%20of%20Barovia.md#en-birth-of-barovia), sauf les origines de la *<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-campagne-brightblade">Lame radieuse</a>* du roi Barov, les liens passés de <a href="../Appendices/Non-Player%20Characters.md#en-baba-lysaga">Baba Lysaga</a> avec les von Zarovich, la naissance de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-sergei-von-zarovich">Sergei</a> et les origines du Magicien des Vins. Il peut cependant exprimer ses forts soupçons : les fondateurs du domaine viticole entretenaient des liens étroits avec les autochtones de la vallée, ou en descendaient.

Si un joueur possède encore un <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-campagne-amber-shard">éclat d'ambre</a>, <a href="../Appendices/Non-Player%20Characters.md#en-sir-godfrey-gwilym">Godfrey</a> lui conseille de « prendre garde à l'intensité avec laquelle il contemple l'abîme » et ajoute : « Chaque instant que vous y passez vous rapproche de son bord. »

S'il a des raisons de croire que les joueurs souhaitent se rendre au Temple de l'Ambre, <a href="../Appendices/Non-Player%20Characters.md#en-sir-godfrey-gwilym">Godfrey</a> peut aussi communiquer les informations suivantes :

* Il y a quelques semaines, un elfe du crépuscule nommé <a href="../Appendices/Non-Player%20Characters.md#en-kasimir-velikov">Kasimir Velikov</a> est venu au manoir et a interrogé <a href="../Appendices/Non-Player%20Characters.md#en-sir-godfrey-gwilym">Godfrey</a> sur l'histoire, l'emplacement et le contenu du Temple de l'Ambre.
* <a href="../Appendices/Non-Player%20Characters.md#en-sir-godfrey-gwilym">Godfrey</a> lui a conseillé d'éviter les ténèbres du temple, mais pense que <a href="../Appendices/Non-Player%20Characters.md#en-kasimir-velikov">Kasimir</a> a néanmoins pu recueillir des informations en parcourant les ruines d'Argynvostholt.
* <a href="../Appendices/Non-Player%20Characters.md#en-sir-godfrey-gwilym">Godfrey</a> n'a pas demandé pourquoi <a href="../Appendices/Non-Player%20Characters.md#en-kasimir-velikov">Kasimir</a> recherchait le Temple, mais ne pense pas qu'il ait eu de mauvaises intentions. « Malgré tout, je ne connaissais que trop bien l'attrait du Temple, dit-il. Je sentais en lui la magie, l'intelligence et le désespoir. De telles personnes sont les proies les plus vulnérables du Temple. »
* Le Temple de l'Ambre se trouve près du sommet du mont Ghakis, au bout d'un sentier oublié depuis des siècles. « Je crois pourtant que l'elfe l'a retrouvé, dit gravement <a href="../Appendices/Non-Player%20Characters.md#en-sir-godfrey-gwilym">Godfrey</a>. Cherchez-le : il pourra peut-être vous conduire là où vous souhaitez aller. »

Lorsque la conversation touche à sa fin, ou si les joueurs demandent une récompense pour avoir ramené son crâne dans sa crypte, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> propose d'investir une de leurs armes non magiques de « la flamme d'un dragon d'argent ». Une arme ainsi bénie gagne les propriétés suivantes :

* L'arme devient une arme magique +1 de son type et possède 3 charges. Elle récupère toutes ses charges dépensées à l'aube.
* Son porteur peut dépenser 1 charge au prix d'une action bonus pour l'embraser de flammes argentées pendant 1 minute. Tant que ces flammes durent, chacune de ses attaques inflige 1d4 dégâts de froid supplémentaires. Si le porteur obtient un coup critique pendant ce temps, la cible doit réussir un jet de sauvegarde de Constitution DD 20 sous peine d'être paralysée jusqu'au début du prochain tour du porteur.
* Son porteur peut dépenser 2 charges au prix d'une action bonus pour lancer *<a href="https://www.aidedd.org/dnd/sorts.php?vf=lueur-d-espoir">lueur d'espoir</a>*.
* Son porteur peut dépenser 3 charges au prix d'une action pour créer un souffle de flammes argentées : un cône de 15 pieds pour une arme de corps à corps, ou une ligne de 30 pieds pour une arme à distance. Chaque créature hostile dans cette zone doit effectuer un jet de sauvegarde de Constitution DD 20 ; elle subit 58 (13d8) dégâts de froid en cas d'échec, ou la moitié de ces dégâts en cas de réussite. Une fois utilisée, cette propriété ne peut plus servir pendant un an.

Après avoir béni l'arme d'un joueur, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> observe qu'« un chemin long et difficile les attend » et leur demande s'ils comprennent vraiment le mal qu'ils affrontent. « Vous connaîtrez des épreuves que la plupart des mortels ignorent, gronde-t-il, et endurerez ce que nul ne devrait endurer. Y êtes-vous prêts ? »

S'ils acquiescent ou demandent son aide, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> lève les yeux vers le phare obscur d'Argynvostholt. « Je ne peux vous accompagner, dit-il solennellement, mais je peux peut-être éclairer votre chemin. » Lisez :

<div class="description">
<p>Des particules de lumière argentée commencent à émaner des écailles spectrales d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a>. « Mes <a href="https://www.aidedd.org/dnd/monstres.php?vf=chevalier">chevaliers</a> ont mérité le repos, dit-il, mais je n'ai pas encore acquitté ma dette ni expié mon échec. » Ses ailes se déploient davantage, parcourues de volutes de flammes argentées. « Comme cette flamme brûle en vous, mon esprit brûlera au sommet du phare d'Argynvostholt pour apporter lumière et espoir à cette sombre contrée. »</p>
<p>Son regard ferme et solennel rejoint le vôtre. « Porterez-vous à ma place l'héritage de l'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-order-of-the-silver-dragon">ordre du Dragon d'argent</a> ? » demande-t-il doucement.</p>
</div>

Si au moins un joueur accepte, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> leur demande de prêter le serment de l'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-order-of-the-silver-dragon">ordre du Dragon d'argent</a>. S'ils y consentent, il le récite en entier, marquant une pause après chaque phrase pour leur permettre de la répéter :

<div class="description">
<p>Je jure solennellement de défendre les vertus de l'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-order-of-the-silver-dragon">ordre du Dragon d'argent</a>, avec l'honneur pour bouclier et la vérité pour guide.</p>
<p>Dans l'ombre du mal, je serai la lumière ; face au désespoir, le flambeau de l'espoir. Nul défi n'ébranlera ma résolution ; nulle défaite n'abattra mon cœur. Par l'épée et par l'esprit, je me dresserai contre les ténèbres et forgerai une aube plus radieuse.</p>
<p>Ainsi je le jure au nom du Dragon d'argent, de ce jour jusqu'à la fin des temps.</p>
</div>

Une fois le serment achevé, les ailes d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> s'affaissent dans un soulagement manifeste. « Merci, murmure-t-il. Vous avez fait davantage pour moi que vous ne le pensez. »

Qu'ils aient prêté serment ou non, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> dit : « Mon esprit servira de phare à la vallée pour que tous sachent que le conflit final approche. Mais cette flamme ne durera guère : vous devez vous hâter, de peur que mon âme se consume avant que vous ayez accompli votre tâche. Comprenez-vous ? »

Si on le lui demande, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> confirme qu'allumer le phare détruira son âme. Elle pourra tenir « un demi-cycle de lune », soit sept jours, « ou peut-être davantage, s'il m'en reste la force », avant d'être entièrement consumée. Il affirme sans hésiter qu'il ne craint pas l'anéantissement de son âme et jugera ce sacrifice amplement justifié s'il permet de libérer la vallée.

Lorsque les joueurs ont répondu à sa dernière question, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> regarde de nouveau le phare et déclare : « Il est temps. » Lisez :

<div class="description">
<p>Lorsque l'esprit d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> ferme les yeux, un son lointain résonne : un chœur de notes graves et grondantes qui font vibrer le sol, mêlées d'aigus nets et limpides qui fendent l'air comme le tintement du cristal. À mesure que l'harmonie s'intensifie, vous comprenez qu'il ne s'agit pas de simples notes, mais de voix : des milliers de voix anciennes, vibrantes et <em>vraies</em>, qui traversent des distances insondables dans un chant sans paroles.</p>
<p>L'esprit d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> devient flou, ses contours s'estompant tandis que des flammes argentées parcourent tout son corps. Elles grandissent à chaque seconde, passant de braises nacrées à un brasier rugissant qui dévore ses griffes, sa queue, ses ailes et, enfin, sa tête.</p>
<p>Alors que le chœur lointain atteint un crescendo fier et farouche, le brasier argenté qui fut <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> <em>vibre</em> de puissance. Il reste un instant suspendu dans les airs, puis s'élance vers le ciel, flamboyant comme une comète, avant de se poser dans la plus haute tour du manoir.</p>
<p>La flamme <em>éclate</em> en une lumière radieuse, une brillante explosion d'argent qui éclipse la clarté du ciel. L'espace d'un instant, le paysage à des milles à la ronde se pare d'argent, de gris et de blanc, chassant les ombres qui fuient cette lumière ardente.</p>
</div>

Poursuivez avec le texte suivant, en l'adaptant à la situation actuelle de chaque personnage non joueur :

<div class="description">
<p>Le temps lui-même semble retenir son souffle tandis que d'innombrables reflets scintillent au cœur de cette radiance, chacun illuminé par la lumière argentée.</p>
<p>Dans ces reflets, la lumière atteint d'abord une ville solitaire ceinte de remparts : Vallaki. Ses lueurs dansent sur le lac Zarovich voisin, autrefois sombre. Elle entre dans la salle commune de l'auberge de l'Eau bleue, où <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-brom-martikov">Brom</a> et <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-bray-martikov">Bray Martikov</a> pressent leurs visages contre la vitre tandis qu'<a href="../Appendices/Non-Player%20Characters.md#en-urwin-martikov">Urwin</a> et <a href="../Appendices/Non-Player%20Characters.md#en-danika-dorakova">Danika</a> contemplent le lointain avec émerveillement. Des ombres d'argent et de blanc se posent sur <a href="../Appendices/Non-Player%20Characters.md#en-muriel-vinshaw">Muriel Vinshaw</a>, dont les yeux se rallument d'une vive étincelle lorsqu'elle se penche en avant, assise sur le comptoir. <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-nikolai">Nikolai</a> et <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-karl-wachter">Karl Wachter</a> regardent les fenêtres, bouche bée, depuis leurs tabourets. À une table proche, <a href="../Appendices/Non-Player%20Characters.md#en-victor-vallakovich">Victor Vallakovich</a> tend une main hésitante vers celle de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-stella-wachter">Stella Wachter</a>, qui la prend et la serre fort.</p>
<p>La lumière serpente dans les ruelles de Vallaki et atteint une rue boueuse devant un vieux taudis délabré. <a href="../Appendices/Non-Player%20Characters.md#en-milivoj">Milivoj</a> et ses frères et sœurs, joyeusement accrochés à ses bras et ses jambes, lèvent les yeux vers le ciel comme s'ils le voyaient pour la première fois. Non loin, d'autres enfants de la fratrie, qui jouent dans la boue avec l'enfant de chœur <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-yeska">Yeska</a>, s'immobilisent, émerveillés. Le père <a href="../Appendices/Non-Player%20Characters.md#en-father-lucian-petrovich">Lucian</a>, qui veille sur eux, serre le soleil rayonnant qu'il porte au cou avec une joie fervente et recueillie.</p>
<p>La lumière atteint une colline au-delà des remparts de Vallaki. Elle perce la fumée qui monte paresseusement des feux du campement, puis trouve <a href="../Appendices/Non-Player%20Characters.md#en-arrigal">Arrigal</a>, les yeux écarquillés, qui laisse tomber une statuette à demi sculptée. Blottie contre la poitrine de <a href="../Appendices/Non-Player%20Characters.md#en-luvash">Luvash</a>, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-arabelle">Arabelle</a> contemple la lumière avec une satisfaction tranquille. Elle tend le bras vers <a href="../Appendices/Non-Player%20Characters.md#en-dr-rudolph-van-richten">Van Richten</a>, à côté d'elle, et lui relève doucement le menton de sa petite main, jusqu'à ce que ses yeux découvrent la lumière et s'emplissent de larmes retenues.</p>
<p>La lumière voyage vers l'est et trouve, au-delà des montagnes, le village de Barovie. L'ombre du château Ravenloft s'en est retirée avec effroi et répulsion, ne serait-ce que pour un battement de cœur. <a href="../Appendices/Non-Player%20Characters.md#en-ismark-kolyanovich">Ismark</a>, un marteau à la main plutôt qu'une épée, lève les yeux d'un mur à moitié construit et se frappe fièrement la poitrine du poing. Dans la rue voisine, <a href="../Appendices/Non-Player%20Characters.md#en-parriwimple">Parriwimple</a>, qui transporte du bois avec <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-bildrath-cantemir">Bildrath</a>, montre le ciel avec une fascination ravie. Un petit sourire fragile effleure les lèvres de son oncle. Non loin, dans une cuisine éclairée aux chandelles, le <a href="../Appendices/Non-Player%20Characters.md#en-father-donavich">père Donavich</a> et <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-mad-mary">Mary</a> lèvent les yeux de leur table, emplis d'espoir. À l'étage, <a href="../Appendices/Non-Player%20Characters.md#en-doru">Doru</a> enlace tendrement la taille de <a href="../Appendices/Non-Player%20Characters.md#en-gertruda">Gertruda</a>, dont la main fine serre sa main griffue contre son cœur.</p>
<p>La lumière voyage aussi vers l'ouest, illuminant le village de Krezk et l'abbaye enneigée qui le surplombe. Elle trouve <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-kala-krezkova">Kala</a> et <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-ilya-krezkov">Ilya Krezkov</a> qui, les joues rouges et riant aux éclats, se jettent dans la neige fraîche qui poudre les rives du bassin sacré de Krezk. <a href="../Appendices/Non-Player%20Characters.md#en-baron-dmitri-krezkov">Dmitri</a> et <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-baroness-anna-krezkova">Anna</a> regardent le ciel depuis le vieux pavillon voisin, deux <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup">loups</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-wolf-monstre"><sup>fiche</sup></a> familiers paisiblement roulés en boule dans la neige près d'eux. Sur le haut éperon rocheux qui domine le village, dans un jardin calme et enneigé, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-otto-belview">Otto</a>, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zygfrek-belview">Zygfrek</a> et <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-clovin-belview">Clovin Belview</a> contemplent la lumière depuis un vieux mur de pierre. Derrière eux, <a href="../Appendices/Non-Player%20Characters.md#en-the-abbot">Ithuriel</a>, <a href="../Appendices/Non-Player%20Characters.md#en-vasilka">Vasilka</a> et un golem silencieux lèvent les yeux de la végétation florissante ; les fleurs dans les mains de <a href="../Appendices/Non-Player%20Characters.md#en-vasilka">Vasilka</a> se parent d'un argent nacré et joyeux.</p>
<p>La lumière voyage vers le sud, touchant des rangées de piquets de bois chargés de vignes verdoyantes, qui ploient sous le poids des raisins pointant entre leurs feuilles. Elle trouve <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-davian-martikov">Davian Martikov</a>, dont la main se referme sur le médaillon suspendu à sa ceinture ; <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-claudiu">Claudiu</a>, qui lève les yeux depuis les ombres du vignoble et contemple le ciel ; et <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-elvir-martikov">Elvir</a>, qui serre la poignée de son <a href="https://www.aidedd.org/regles/equipement/armes/">épée courte</a> tandis qu'une compréhension solennelle éclaire son visage.</p>
<p>La lumière atteint les toits sombres et tortueux du château Ravenloft, où <a href="../Appendices/Non-Player%20Characters.md#en-sasha-ivliskova">Sasha Ivliskova</a> se tient seule, le visage tordu par la douleur d'un espoir soudain. Elle trouve un cairn solitaire dans les bois de Svalich, où l'esprit de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-kavan">Kavan</a> relève la tête, plein de souvenirs et de chagrin. Enfin, elle trouve le perron affaissé d'un vieux manoir fatigué, où <a href="../Appendices/Non-Player%20Characters.md#en-lady-fiona-wachter">dame Fiona Wachter</a> porte une main tremblante à son visage tandis que des larmes coulent sur ses joues.</p>
<p>Puis l'instant passe, les reflets disparaissent et le jour revient lentement. Le chant lointain s'éteint lui aussi, laissant des notes de chagrin, de souvenir et de défi qui se dissipent bientôt dans le silence. Le phare d'Argynvostholt continue pourtant de briller, baignant les bois et les vallées en contrebas d'une éclatante radiance argentée.</p>
<p>
</div>

Toutes les créatures qui s'opposent à <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-strahd-von-zarovich">Strahd</a>, y compris les joueurs, bénéficient alors du ***Phare de protection*** décrit dans <span class="citation">Allumer le phare (p. 142)</span>.

***Jalon.*** Ramener le crâne d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a> dans sa crypte constitue un jalon de l'histoire. Lorsque les joueurs allument le phare d'<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-argynvost">Argynvost</a>, accordez 3 000 PX à chacun. (Cela devrait leur permettre d'atteindre le niveau 8.)

# Q7. Retour à l'antre des loups-garous

> [!abstract]+ **Combattre <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a>**
> Les joueurs que <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> ne traque pas dans [Q5. L'attaque de la meute](#en-q5-pack-attack) peuvent le rencontrer de nouveau de deux manières :
>
> * S'ils arrivent à l'antre des <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup-garou">loups-garous</a> <a href="../Appendices/Bestiary.md#en-werewolf"><sup>fiche</sup></a> de jour, <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> dort dans la <span class="citation">Z6. Grotte de <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> (p. 204)</span>, sous forme de <a href="https://www.aidedd.org/dnd/monstres.php?vf=loup-sanguinaire">loup sanguinaire</a> <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-dnd-dire-wolf-monstre"><sup>fiche</sup></a>.
> * S'ils arrivent à l'antre de nuit, <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> et la meute sont partis chasser, mais reviennent plus tard comme décrit dans <span class="citation">Chef de meute (p. 205)</span>.
>
> Si un combat éclate dans l'antre, <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> préfère l'entraîner à l'extérieur. La scène se déroule autrement dans l'ensemble comme décrit dans [Q5. L'attaque de la meute](#en-q5-pack-attack).

Une fois <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> vaincu, les joueurs peuvent facilement libérer <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-ilya-krezkov">Ilya</a> et <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zuleika-toranescu">Zuleika</a> de leurs *<a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-campagne-silverthorn-collar">colliers d'épine d'argent</a>* avec les clés de la chaîne de <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a>.

Si les joueurs ont sauvé <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a> du château Ravenloft, <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a> et <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-zuleika-toranescu">Zuleika</a> les laissent volontiers prendre tous les trésors du sanctuaire de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-mother-night">Mère Nuit</a> sans encourir la malédiction de la déesse. (« <a href="../Appendices/Non-Player%20Characters.md#en-kiril-stoyanovich">Kiril</a> s'est emparé de la plupart de ces richesses, dit tristement <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-emil-toranescu">Emil</a>. Il les a volées à leurs propriétaires légitimes au-delà des brumes lors de ses nombreux raids sanglants. Nous n'avons pas plus de droits sur elles que vous. ») Outre les trésors décrits dans le <span class="citation">Z7. Sanctuaire de <a href="../Appendices/Index%20des%20personnages%20et%20cr%C3%A9atures.md#ref-nom-mother-night">Mère Nuit</a> (p. 204)</span>, le butin contient un diamant valant 300 po.
